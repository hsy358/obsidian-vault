# 大宗商品牛市轮动顺序

> 何大人 2026-08-31 09:42 转发 · 中文信息图 · 1280×2769

## 信息图四阶段框架

| 阶段 | 主题 | 关键品种 | 经济周期 | 驱动逻辑 |
|---|---|---|---|---|
| ① 金融预期先行 | 贵金属领涨 | 黄金→白银（黄金领先 1–2 月） | 避险 | 货币宽松 / 地缘风险 / 信用风险 |
| ② 工业需求确认 | 工业金属接棒 | 铜→铝→钢铁→铅锌（"铜博士"领先） | 复苏 | 实体复苏 / 工业补库 / 基建制造 |
| ③ 能源成本传导 | 能源化工崛起 | 原油→天然气/煤炭→化工品（乙烯/塑料） | 通胀 | 工业全面回暖 / 供给约束 / 原料涨价 |
| ④ 民生终端扩散 | 农产品收尾 | 大豆/玉米/小麦→棉花/糖→油脂 | 滞胀 | 能源推高农业成本 / 极端天气 / 政策干预 |

## 一句话核心逻辑

> **金融属性 → 工业属性 → 能源消费属性 → 民生刚需属性**
>
> **避险 → 复苏 → 通胀 → 滞胀**

## 我的客观评价

- ✅ **框架正确**：本质上就是「美林时钟 + 商品周期」的中国化版本，逻辑链是对的
- ⚠️ **过度简化**：四阶段是"教科书理想态"，实战里阶段会重叠、会跳跃（铜可能跟黄金一起涨）
- ⚠️ **"牛市真的来了"是情绪语言**：信息图顶部红色横幅属于零售喊单口吻，不是研究观点——**信号意义大于信息意义**
- 🎯 **真正能用的观察指标**：
  - 黄金/铜价比（金铜比）— 比率下降 = 工业金属追上贵金属 = 进入第二阶段
  - 油价/煤价比 — 比率走阔 = 通胀传导开始
  - 农产品/原油价比 — 比率快速下降 = 进入滞胀尾部
- ❌ **不要拿来直接抄作业**：框架是「事后来看都对」的归纳，不是「事前能预测」的因果
