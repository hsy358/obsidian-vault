# 保利集团 AI 能力建设与产业化规划建议 v1.7 —— 内容摘要

> 本文件是 [2026-08-28_pdf_保利集团AI运营与企业主权AI战略规划建议_v1.7.pdf] 的 sidecar 元数据。
> 原文件为二进制 PDF（约 14 页），作者：**锦曜新宸科技**。

## 一、文档定位

> **核心判断**：保利下一阶段不只是"建设 AI"，而是要形成可持续运营、持续进化、可以对外输出的集团 AI 能力。

从"采购和使用 AI" → 升级为 → "拥有、运营并持续进化 AI 能力"。

## 二、领导层最终需要看到的三件事

1. 自主 AI 能力
2. 重点业务规模提效
3. 新产业与新品牌

## 三、美的启示（核心叙事框架）

> **关键判断**：美云智数是内部数字化实践的承载者和放大器，**而不是数字化转型的起点**。

| 阶段 | 时间 | 关键动作 |
|---|---|---|
| 内部变革 | 2012—2015 | "632"推进：实现"一个美的、一个体系、一个标准" |
| 专业承载 | 2016 | 成立美云智数 |
| 平台产品化 | 2018—2022 | 工业互联网平台、全价值链解决方案与产品线 |
| 产业化扩张 | 2023—2025 | 平台化、产品化、智能化 → 行业化、生态化 |

**演进路径**：集团战略 → 业务验证 → 专业主体 → 平台产品 → 外部产业

## 四、领导关心的五个集团级结果

1. **规模化提效** — 在重点业务域形成可复制、可持续的效率红利
2. **自主 AI 能力** — 业务使用持续沉淀为评估、反馈与领域模型
3. **稳定 AI 供给** — 统一模型服务、容灾与 SLA
4. **安全与供应链可控** — 国产算力、多租户隔离、模型/数据/运行可替换
5. **新的业务形态** — 内部能力产品化，对外 AI 服务、行业能力与品牌

## 五、保利当前四层缺口

| 层面 | 已有 | 缺口 |
|---|---|---|
| 战略层 | 人工智能+新保利、智算中心、高价值场景 | 集团 AI 目标模型与长期路线 |
| 组织层 | 各板块业务与技术团队 | 统一的 AI 能力运营主体 |
| 技术层 | 模型、数据与算力基础 | Learning Loop、Agent 控制、多租户 |
| 实施层 | PoC 与局部应用 | 可复制业务模板与经营指标 |

**关键问题**：项目做完以后，业务知识、评估标准、运行反馈和模型能力是否真正沉淀在保利？

## 六、核心新概念：企业主权 AI（Enterprise Sovereign AI）

> **核心理念**：企业不必从头训练基础模型，但必须掌握六项关键控制权。

| # | 主权 | 含义 |
|---|---|---|
| 1 | 数据与知识主权 | 数据、规则、上下文与记忆由保利掌握 |
| 2 | 模型选择主权 | 国产、开源与商业模型可动态替换 |
| 3 | 运行与算力主权 | 集团智算、国产 GPU 与专属云可切换 |
| 4 | Agent 控制主权 | 控制读取、工具、操作、停止与审批条件 |
| 5 | 评估与反馈主权 | 正确性、合格标准和反馈由企业定义 |
| 6 | 模型进化主权 | 任务反馈可用于后训练与领域模型 |

**公式**：数据可控 + 模型可替换 + 过程可治理 + 结果可评估 + 能力可进化

## 七、目标架构：1 + 1 + N

```
1 个 AI 能力运营主体（战略治理中枢 + 产品研发 + 业务共创 + 模型数据运营 + 内外市场）
+ 1 个保利企业主权 AI 平台（AI Gateway / Context / Compute / Agent Runtime / Eval & Learning Loop / Multi-tenant Security）
+ N 个领域智能（工程与项目 / 轻工·生物制造 / 地产·物业 / 文化·文旅 / 其他）
```

## 八、五大能力支柱

| # | 支柱 | 核心 |
|---|---|---|
| 01 | AI Learning Loop | 任务 → 反馈 → 后训练 → 领域模型 |
| 02 | 稳定 AI 服务 | 多模型路由、容灾、SLA、统一运营 |
| 03 | 低成本国产算力 | 少 Token + AI Gateway + 任务感知调度 |
| 04 | 多租户可信 AI | 分域数据、记忆、权限、审计、成本 |
| 05 | 外部能力输出 | 主权 AI 平台、领域模型包、运营服务 |

> **FormSy 定位**：连接业务任务/企业上下文/Agent/模型/算力/反馈学习的"控制与学习平面"。
> 边界：不替代基础模型、推理平台和业务系统；可理解为"保利内部的 Fireworks，但更强调企业主权、多租户与国产算力"。

## 九、业务方法论：一横多纵

**一横（通用 AI 工程）**：软件工程 / 数据工程 / Agent 开发 / 测试与质量 → **跨业务、易测试、易量化、适合首期规模化**

**多纵（领域智能）**：工程与项目 / 轻工·生物制造 / 地产·物业 / 文化内容 → **业务反馈进 Learning Loop，逐步形成领域模型**

**场景选择五标准**：① 高频 ② 知识密集 ③ 可验证 ④ 可复用 ⑤ 具备外部市场

## 十、三阶段演进

| 阶段 | 时间 | 关键动作 | 阶段结果 |
|---|---|---|---|
| 一·内生验证 | 0—6 月 | 1 横 + 1 纵、首个 Learning Loop、验证国产 GPU、运营主体雏形 | 证明业务使用能沉淀为保利 AI 能力 |
| 二·集团平台化 | 6—18 月 | 多租户 AI 公共服务、统一服务目录与 SLA、首批领域模型与 Agent、集团 AI 运营体系 | 从项目建设升级为集团公共能力运营 |
| 三·产业化运营 | 18—36 月 | 标准企业主权 AI 平台、行业模型包、外部灯塔客户与市场收入、资本/合资可选项 | 从内部能力中心升级为市场化 AI 企业 |

## 十一、给集团的三项立即行动

1. 启动联合总体规划
2. 明确 AI 能力承载主体
3. 选择"1 横 1 纵"首批场景
