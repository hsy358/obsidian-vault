# 行为金融 动量反转 止损学术梳理

> **目的**：把动量/反转效应的学术结论**翻译成我们能用的因子**。
> **拒绝**：不空谈理论，要落地到脚本。

## 📚 核心文献 5 篇

### 1. Lehmann (1990) — 短期反转

**结论**：股票月度收益存在**显著反转效应**——过去 1 个月跌的股票，未来 1 个月倾向于涨；过去涨的，未来倾向于跌。

**机制**：投资者认知偏差（过度反应/代表性偏差）→ 价格偏离 → 回归。

### 2. Jegadeesh (1990) — 月度反转

**独立证实** Lehmann 结论。
**量化**：月度反转策略年化收益约 12-15%（扣除成本前）。

### 3. Jegadeesh & Titman (1993, 2001) — 中期动量

**结论**：过去 2-12 个月涨的股票，未来 2-12 个月继续涨——**动量效应**。

**重要细节**：
- 排除最近 1 个月（避免短期反转污染）
- 中期动量是 12-month momentum excluding the most recent month
- 月度反转 + 中期动量 **同时存在**，不同时间尺度

### 4. De Bondt & Thaler (1985) — 长期反转（里程碑）

**结论**：过去 3-5 年表现最差的股票（losers），未来 3-5 年**显著跑赢**赢家（winners）。

**机制**：投资者**过度反应**——坏消息砸过头，好消息推过头。

**A股验证**：A 股"低估值反转"长期有效（小盘股更明显）。

### 5. Sadaqat & Butt (2023) — 加密货币止损 + 动量

**Journal of Behavioral and Experimental Finance, Sep 2023**

**结论**：
- 止损规则 + 动量策略的组合，**显著优于**单独动量
- 止损阈值 5%-15% 效果最好（过紧砍掉盈利，过松放大亏损）
- 加密货币市场表现一致

## 🎯 把学术翻译成因子

### 因子 1：短期反转（1 个月）

**逻辑**：今天跌多的票，未来 1-2 周反弹概率高。
**用法**：
- 持仓票当日跌 > 7% → 标记"短期反弹候选"
- 不立刻卖，等 2-3 天观察反弹
- 反弹 +2% 以上 → 减仓 1/3

### 因子 2：中期动量（2-12 个月）

**逻辑**：过去半年涨得好的票，未来 2-3 个月继续涨。
**用法**：
- 推荐股必须**过去 6 个月有正收益**（动量因子 > 0）
- 持仓股 6 个月动量转负 → 触发"动量衰减"预警

### 因子 3：长期反转（3-5 年）

**逻辑**：深度套牢的票（输家）有"估值修复"潜力。
**用法**：
- 上能电气（套 -27%）：属于长期反转候选
- 但**前提**：基本面没恶化（行业景气度还在）
- 当前储能/电力电子基本面 OK → **可以持有等反弹**

### 因子 4：行为偏差识别

**De Bondt & Thaler 七大偏差**（Barberis & Thaler 2002 综述）：

| 偏差 | 投资表现 |
|---|---|
| **过度自信** | 频繁交易、过度集中 |
| **乐观/希望思维** | 套牢不肯割，"再等等会回来" |
| **代表性偏差** | "这次不一样"，追涨杀跌 |
| **保守主义** | 忽视新信息 |
| **信念坚持** | 找证据支持已有判断 |
| **锚定** | 锚定成本价，"回本就卖" |
| **可得性** | 最近的事过度反应 |

**给何大人的自检清单**（持仓时）：
1. 我是"回本就卖"还是"涨回去再加仓"？—— **警惕锚定偏差**
2. 我是因为今天跌多而恐慌割肉吗？—— **警惕过度自信 + 情绪化**
3. 我是不是只看到支持持有的证据？—— **警惕信念坚持**

### Factor-1：持仓动量衰减监控

```python
# /root/.openclaw/workspace/skills/stock-recap/factor_momentum.py
import akshare as ak
import pandas as pd

def check_momentum_decay(code, days=120):
    """检查持仓 6 个月动量"""
    df = ak.stock_zh_a_hist(code, period='daily', adjust='qfq').tail(days)
    if df.empty:
        return None
    return_pct = (df['close'].iloc[-1] / df['close'].iloc[0] - 1) * 100
    
    # 阈值
    if return_pct > 30:
        signal = '🚀 强势动量（>30%）'
    elif return_pct > 0:
        signal = '🟢 正常动量'
    elif return_pct > -15:
        signal = '🟡 弱动量'
    else:
        signal = '🔴 动量衰减（<-15%）'
    
    return {'code': code, 'return_6m_pct': return_pct, 'signal': signal}

# 实操
for c in ['300827', '603667', '002703']:
    print(check_momentum_decay(c))
```

## 📚 学术结论的"风险提示"

### 短期反转
- ⚠️ 在 A 股的"小盘股 + 高换手"特征下更明显
- ⚠️ 但**跌停板上不要接刀**（连续跌停不算反转，是流动性危机）

### 中期动量
- ⚠️ 2009 年后 A 股动量因子明显衰减（价值因子回归）
- ⚠️ 单一动量不够，**动量 + 低估值**才稳（A股特色）

### 长期反转
- ⚠️ 必须先确认**基本面没恶化**——ST 股 / 退市股"反转"是归零
- ⚠️ A 股小盘股长期反转最明显，但流动性差

### 行为偏差
- ⚠️ "知道了"≠"能做到"——偏差明知故犯是常态
- ⚠️ **用规则**对抗偏差（写死的止损线）> 用认知对抗偏差
