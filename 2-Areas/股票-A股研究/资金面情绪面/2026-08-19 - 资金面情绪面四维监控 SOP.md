# 资金面情绪面四维监控 SOP

> **背景**：今天大跌 -4% 创业板，事前没预警。
> **根因**：我们只看 K 线/量价，没看资金面。

## 🎯 四维监控矩阵

| 维度 | 性质 | 频率 | 数据源 | 解读 |
|---|---|---|---|---|
| **北向资金** | 外资态度 | 日 | akshare `stock_hsgt_*` | 持续流入=信心恢复 |
| **主力资金** | 机构+游资混合 | 日 | akshare `stock_individual_fund_flow_rank` | 中短期情绪方向 |
| **融资余额** | 杠杆情绪 | 日 | akshare `stock_margin_sse/szse` | 杠杆激增=激进，骤降=恐慌 |
| **龙虎榜** | 游资动向 | 日 | akshare `stock_lhb_*` | 机构+游资共振=真行情 |

## 📊 北向资金深度解读

### 性质分类
- **长线稳定型外资**：养老金/主权基金，季度调仓，看 5 年
- **短线灵活型外资**：对冲基金/量化，日内调仓，看 1 周

### 2026 Q1 数据（参考）
- 北向整体净流出 142 亿
- 长线稳定流入 10 亿（"聪明钱"没跑）
- 短线灵活流出 223 亿（对冲基金降仓）

**结论**：长短线分化时，看长线；短线流出但长线没动 → 中长期信号。

### 行业结构（2026 Q1）
| 方向 | 净流入（亿）| 主题 |
|---|---|---|
| 通信 | +225 | AI 算力 |
| 电力设备 | +191 | 新能源 |
| 机械设备 | +92 | 机器人/机床 |
| 有色金属 | -162 | — |
| 非银金融 | -138 | — |
| 汽车 | -135 | **← 何大人持仓所在赛道** |

**风险信号**：汽车板块北向已连续 2 个季度净流出，**智能驾驶/汽车零部件**是外资撤退方向。

## 💰 融资余额 SOP

### 接口
```python
# 沪市融资融券汇总（akshare）
df = ak.stock_margin_sse(start_date="20260101", end_date="20260819")
df = ak.stock_margin_detail_sse(date="20260819")
# 深市
df = ak.stock_szse_margin(start_date="20260101", end_date="20260819")
```

### 信号
| 阈值 | 信号 |
|---|---|
| 余额日环比 > +2% | 杠杆资金加速进场 |
| 余额日环比 < -1.5% | 杠杆资金退潮（警惕） |
| 余额 5 日累计 < -3% | 系统性去杠杆（强烈减仓信号）|

**坑**：2024 年 2 月雪球敲入 + 杠杆爆仓就是融资余额 5 日骤降 5%+ → A 股单日 -7%。

## 🎰 龙虎榜 SOP（最重要！）

### 接口
```python
df = ak.stock_lhb_detail_em(start_date="20260819", end_date="20260819")
df = ak.stock_lhb_ggtj_sina(indicator="机构买卖每日明细")
```

### 关键规则（情绪因子）
1. **机构净买入 > 游资净买入** → 中长期看好
2. **游资净买入 > 机构** → 短期炒作，跟随但不重仓
3. **机构+游资同方向** → **情绪共振，最强信号**
4. **游资买机构卖** → **典型出货，规避**

### 案例（参考）
- 金风科技 2025-12-25 至 2026-01-09：游资独舞，机构撤退 → 后续冲高回落 ❌
- 大普微 2026-04-16 上市：机构+游资共振 +430% → 持续性强 ✅

**给何大人的实操**：
- 持仓票每日 18:00 拉龙虎榜数据
- 出现"游资买+机构卖"模式 → 当日推送"出货预警"

## 🛠️ v6 落地代码骨架

```python
# /root/.openclaw/workspace/skills/stock-research/scripts/capital_monitor.py
import akshare as ak
import pandas as pd

def monitor_all():
    """每日 15:30 跑一次"""
    report = {}
    
    # 1. 北向 5 日累计
    df = ak.stock_hsgt_north_net_flow_in_em(market="北向")
    report['north_5d'] = df.tail(5)['净买额'].sum()
    
    # 2. 主力 5 日累计
    df = ak.stock_individual_fund_flow_rank(indicator="5日")
    report['main_5d_top10'] = df.head(10)[['名称', '5日主力净流入']].to_dict('records')
    
    # 3. 融资余额环比
    df = ak.stock_margin_sse(start_date=..., end_date=...)
    report['margin_change_pct'] = (df.iloc[-1]['融资余额'] / df.iloc[-2]['融资余额'] - 1) * 100
    
    # 4. 持仓票龙虎榜检查
    holdings = ['300827', '603667', '002703']
    lhb = ak.stock_lhb_detail_em(...)
    report['holdings_on_lhb'] = [r for r in lhb.to_dict('records') if r['代码'] in holdings]
    
    return report
```
