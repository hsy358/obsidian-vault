# 板块轮动与行业联动预警

> **背景**：今天浙江世宝（智能驾驶）暴跌 -8%，五洲新春（汽车零部件）暴跌 -10%——**板块系统性下跌**，我们没识别。

## 🎯 核心问题

我们当前有：
- ✅ 涨停板行业分布（哪几个行业涨停多）
- ✅ 主线识别（哪个行业有龙头）
- ❌ **没有"持仓所在行业整体在跌"**的提示

**应该有的提示**：
- "今天智能驾驶 ETF 跌 -6%，你持仓的浙江世宝跌 -7%，属于板块共振下跌，不是孤例"
- "汽车零部件 ETF 连续 5 日净流出，建议减仓"

## 📚 4 套板块轮动方法

### 方法 1：中信证券「趋势配置+行业预警」组合 ⭐⭐⭐（最推荐）

**机制**：
- 选 45 个流动性好、相关性低的行业主题 ETF
- 用**趋势跟踪**（动量因子）+ **行业预警**（流动性/波动率/成分股收益分布/融资融券）
- 2014-2026.5 年化 20.38%，超额 13.32%

**给我们用的简化版**：
- 只挑 5 个 ETF：智能驾驶 / 汽车零部件 / 储能 / 银行 / 红利
- 每周一判断：哪些在多头排列 → 加仓；哪些破位 → 减仓
- 预警：ETF 当日跌幅 > -3% + 融资余额环比下降 → 推送板块风险

### 方法 2：中信「SDISS 多维共振」

**机制**：景气度（盈利）+ 预期（分析师）+ 技术（动量）+ 估值（PE/PB）4 维打分
**频率**：周
**回测**：2020-2026.4 年化 18.1%，回撤 < 基准

**给我们用的简化版**：每周末给持仓所在 3 个板块打 0-100 分，< 60 触发减仓

### 方法 3：行业景气度 ETF 轮动（富国 + 国联）

**核心**：用 ROE 周期判断景气拐点
- **景气上行** = 股价上涨充分条件（华泰证券研究）
- **戴维斯双击**：短周期景气 + 中周期景气叠加
- **买点**：短周期不景气 + 中周期景气（杀业绩但估值合理）

**vs 我们**：akshare 能拉 `stock_zyjs_ths`（同花顺行业指数），可以做 ROE 排序

### 方法 4：宏观状态驱动 ETF 轮动（中信）

**机制**：用 SPX/M2SL 等高频指标判断 10 类宏观状态（增长/通胀/利率/汇率...）
**A 股化**：替换为
- 增长：PMI / 工业增加值
- 通胀：CPI / PPI
- 利率：10Y 国债收益率
- 汇率：USDCNH
**按状态映射板块**：复苏买金融/周期，过热买消费/医药，滞胀买红利

### 预警 SOP（每日 14:30）

```python
# /root/.openclaw/workspace/skills/stock-research/scripts/sector_alert.py
import akshare as ak

HOLDINGS = {
    '300827': {'industry': '电力设备', 'etf': '159566'},   # 上能电气
    '603667': {'industry': '汽车零部件', 'etf': '562500'}, # 五洲新春
    '002703': {'industry': '汽车零部件', 'etf': '515250'}, # 浙江世宝
}

def check_sector_alert():
    alerts = []
    # 拉所有持仓对应 ETF 实时价
    for code, meta in HOLDINGS.items():
        # 拉 ETF 实时
        df = ak.fund_etf_spot_em()
        etf_row = df[df['代码'] == meta['etf']]
        if not etf_row.empty:
            change_pct = etf_row['涨跌幅'].values[0]
            # 触发条件
            if change_pct < -3.0:
                alerts.append(f"🔴 {meta['industry']} ETF {meta['etf']} 跌 {change_pct:.2f}%, 持仓票 {code} 大概率跟跌")
            elif change_pct < -1.5:
                alerts.append(f"🟡 {meta['industry']} ETF {meta['etf']} 跌 {change_pct:.2f}%, 注意")
    
    return alerts if alerts else ["✅ 持仓所在板块正常"]
```

### 多板块共振检测

**情景**：3 个持仓中 2 个在同一行业，今天都跌 8%+
- **结论**：板块系统性风险，不是单票问题
- **动作**：减仓该板块持仓的 50%

```python
def check_sector_resonance():
    # 今天跌幅 > 5% 的票
    heavy_loss = [c for c in holdings if pct_change(c) < -0.05]
    # 同行业 ≥ 2 只
    industry_count = {}
    for c in heavy_loss:
        ind = get_industry(c)
        industry_count[ind] = industry_count.get(ind, 0) + 1
    
    for ind, count in industry_count.items():
        if count >= 2:
            return f"🚨 {ind} 板块共振下跌 {count} 只持仓，建议减仓"
```
