## 🟢 v6 升级的 6 大模块

### 模块 1：大盘情绪预警（08:30）

**目标**：每日盘前判断"今天能不能加仓 / 是否要减仓"
**核心**：GSISI 情绪指数简化版 + 5 个大盘指标

```python
# 评分 0-100
def market_score():
    scores = {
        '上证 MA 排列': ma_trend_score('000001'),       # 30%
        '北向 5 日': north_5d_score(),                  # 20%
        '融资余额环比': margin_change_score(),            # 20%
        '涨停/跌停比': limit_ratio_score(),              # 15%
        '银行避险溢价': bank_premium_score(),            # 15%
    }
    return weighted_total(scores)
```

**判断阈值**：
- > 70 → 🟢 加仓窗口
- 50-70 → 🟡 持有
- 30-50 → 🟠 减仓 30%
- < 30 → 🔴 减仓 50%

### 模块 4：组合风控（15:30）

**目标**：组合层面止损（vs v4 单票止损）

```python
def portfolio_risk():
    pnl_today = portfolio_pct_change('today')
    pnl_5d = portfolio_pct_change('5d')
    pnl_20d = portfolio_pct_change('20d')
    
    if pnl_today < -3.0:
        yield "🟠 组合日跌 -3% → 推送预警"
    if pnl_5d < -7.0:
        yield "🔴 组合 5 日跌 -7% → 强制减仓"
    if pnl_20d < -15.0:
        yield "🔴🔴 组合 20 日跌 -15% → 减仓 50%"
```

### 模块 5：动量因子监控（每日）

**目标**：6 个月动量衰减预警

```python
def momentum_check(code, days=120):
    return_pct = calc_return(code, days)
    if return_pct > 30: signal = '🚀 强势'
    elif return_pct > 0: signal = '🟢 正常'
    elif return_pct > -15: signal = '🟡 弱'
    else: signal = '🔴 衰减'
    return signal
```

### 模块 6：凯利仓位测算（手动）

**目标**：每只新仓位参考凯利公式

```python
def kelly_position(win_rate, win_loss_ratio):
    full_kelly = (win_rate * win_loss_ratio - (1 - win_rate)) / win_loss_ratio
    half_kelly = full_kelly / 2
    return min(half_kelly, 0.25)  # 上限 25%
```
