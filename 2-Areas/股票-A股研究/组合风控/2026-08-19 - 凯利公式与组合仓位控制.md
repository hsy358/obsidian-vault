# 凯利公式与组合仓位控制

> **背景**：我们 v4 只有"单票 -8% 止损硬规则"。
> **缺口**：没有**单笔仓位上限**，没有**组合层面止损**。
> **目标**：把"一笔亏多少"+"持仓亏多少"两条线都管起来。

## 🎯 5 种仓位管理方法对比

| 方法 | 核心思想 | 优点 | 缺点 | 适合 |
|---|---|---|---|---|
| **Fixed** | 固定比例（如每笔 2%）| 简单易执行 | 忽略波动率变化 | 新手 / 入门 |
| **Kelly** | f* = (bp - q) / b | 长期资金最大化 | 参数敏感，易爆仓 | 学术 / 老手 |
| **Volatility-Scaled** | 按 ATR/历史波动率动态调整 | 实际风险恒定 | 需要稳定波动率估计 | 机构最广 |
| **Equal Weight** | 等权分配 | 简单不集中 | 高波动资产被低估 | 标的波动率相近 |
| **Risk Parity** | 各资产风险贡献相等 | 抗系统性风险 | 桥水专利，复杂度高 | 全天候配置 |

**桥水全天候**（Risk Parity 鼻祖）：2008 金融危机抗跌。

## 📐 凯利公式精要

### 公式
```
f* = (bp - q) / b
```
- b = 赔率（盈亏比）
- p = 胜率
- q = 1 - p = 败率

### 实操（索普改良）

**核心 3 原则**：
1. **每笔交易前问**：我看好的逻辑是什么？错了最多亏多少，我能承受吗？
2. **仓位与确信度挂钩，不是预期收益挂钩**（芒格原话）
3. **单笔仓位设硬上限**（即使凯利算出来 30%，上限 25%）

### 关键洞察（索普实战）
- 连续做错 5 笔，总亏损 15%，账户仍可运行
- 单笔仓位 20% + 止损 15% = 单笔最多亏总资金 3%
- **方向判断可以错，仓位和止损不能错**（决定账户能否持续）

## 📐 范撒普博士风险百分比公式

**核心**：买入数量 = 总资金 × 风险比例 ÷ 每股止损幅度

### 三步法
1. **设定单笔亏损上限 C**：单只股票最大亏不超过总资金 **2%**
   - 例：10 万本金 → 单次亏 ≤ 2000 元
2. **确定止损幅度 R**：用技术分析找到支撑位，计算"现价 - 止损价"
   - 例：现价 36，止损 34，R = 2 元
3. **计算买入数量 P**：P = C / R
   - 例：2000 / 2 = 1000 股 → 实际投入 36000 元

**关键约束**：即便股价跌到止损位，**总亏损仍 ≤ 2%**。

#### 规则 B：组合层面止损

| 阈值 | 触发动作 |
|---|---|
| 组合日跌幅 < -3% | 推送"组合风险预警"，建议减仓 1 只最弱 |
| 组合周跌幅 < -7% | 推送"强制减仓"，减持仓的 30% |
| 组合月跌幅 < -15% | 推送"组合止损"，减持仓的 50% |

#### 规则 C：凯利仓位测算

```python
# /root/.openclaw/workspace/skills/stock-recap/position_kelly.py
def kelly_position(win_rate, win_loss_ratio, total_capital):
    """
    win_rate: 胜率（如 0.55）
    win_loss_ratio: 盈亏比（如 2.0 = 平均赚 2 块亏 1 块）
    """
    kelly_pct = (win_rate * win_loss_ratio - (1 - win_rate)) / win_loss_ratio
    # Half Kelly = 减半，更稳
    half_kelly = kelly_pct / 2
    return {
        'kelly_full': f"{kelly_pct*100:.1f}%",
        'kelly_half': f"{half_kelly*100:.1f}%",
        'recommended_max': f"{min(half_kelly, 0.25)*100:.1f}%"  # 不超过 25%
    }

# 示例
# 胜率 55%，盈亏比 2.0
# f* = (0.55*2 - 0.45)/2 = 0.325 → 32.5%（理论）
# Half Kelly = 16.25%（建议）
# 上限 25% → 取 16.25%
```
