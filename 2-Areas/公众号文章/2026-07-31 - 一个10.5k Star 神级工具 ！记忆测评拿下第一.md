## 光说功能还不够，真正的考验在统一评测

市面上的记忆产品并不少，但是一直缺一个**统一、透明、可复现的评价体系**。

过去不同 Memory 产品的测试结果，很难直接比较。

因为大家使用的：模型不同； **Agent 环境不同； Prompt 不同；  检索策略不同；  评测标准不同。**

最后大家都说自己效果很好，但很难判断谁真的更适合真实场景。

这就像不同学生参加了不同的考试。

有人题目简单，有人可以翻书，有人考试时间更长，最后公布的却是同一张成绩单。

这次 OmniMemEval 做的，就是先把试卷和评分标准统一。

**相同的数据集、相同的回答模型、相同的Prompt、相同的Judge和指标逻辑，将不同的Memory系统接入到一个评测流程当中。**

评测分两条线进行：

一条是Agent Memory，看记忆是否能够提高Agent完成复杂任务的概率。

另一条是User Memory，看系统是否能长期记住用户的事物、喜好、经历、时间变化以及遗忘需求

前面的亲子游案例考的其实是User Memory：

半个月前说过的信息能被正确地保存下来吗？

“孩子对海鲜过敏”是长期限制还是只在本次对话中起作用？

当我需要再安排行程的时候，系统是否可以自动调用上一次的记忆，而不需要我再提醒 ？

而当 Agent 开始搜索酒店、筛选餐厅、安排行程的时候，问题又进入了 Agent Memory：它能不能在长任务里持续保持状态，并把记忆转化为最终交付？

**01 Agent Memory 评测：任务完成率能稳住**

评测中包含 OpenClaw 和 Hermes 两种 Agent 环境下进行的五项长程任务：

在OpenClaw环境中，MemOS在五项任务上的平均准确率为50.07%，表现最佳。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/VDCUoW3UiblJK3EW8PoHfnS5JobbdBAaVIO7ZHvoXNwcJ1hIhCeCuItC9icbMhxHWnZAC0YmYaeudPYhZaNHTjGgdcicB5VSZx50B25VSwOqg0/640?wx_fmt=png&from=appmsg)
Hermes：有记忆能力，接入之后从45.15% 也提高到 53.05%

![](https://mmbiz.qpic.cn/sz_mmbiz_png/VDCUoW3UiblLibVety4M11EGYk5khqw1C6w8ZA63esDDoMaSzsAuxvC1KtmhgLAccqxCUicR79ueib9ZllsD6Ab8JhzpicM1icbeYWxnic62gmeMLA/640?wx_fmt=png&from=appmsg)
**Hermes 本身就是一个注重任务执行、自我反思和经验积累的Agent。**

**但即使在这样的基础上，接入 MemOS 后，五项任务的平均完成率仍然从 45.15% 提升至 53.05%。**

**这说明 MemOS 的效果并不依赖某一种 Agent 架构。**

不管是OpenClaw，还是本身具有较强记忆和进化能力的Hermes，在接入了同一个Memory系统之后，在多个长程任务中都能够再现提升。

**02 用户记忆评测：用户长时间内对信息的理解更准确**

LoCoMo 横评包含 14 种 Memory 方案。

在相同的配置下，MemOS 88.83 Overall 是本次测评中得分最高的。

平均Context Token为5400，远低于其他方案的1.7万到3.2万。

更高的分数来自更有效的记忆抽取和检索，而不是更长的上下文堆叠。

在LongMemEval横评里，MemOS获得了89.20的Overall，排名第一。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/VDCUoW3UiblKtVPE5KmshPNm8L3b3O24MCMicB6E1fQcHaYTjwpDI9IXstvNs1Iya5Z29oicOoZthgU0C4wfk6GuMiaQ853CQZWyRNicfn6au53g/640?wx_fmt=png&from=appmsg)
PersonaMem-v2 关注个性化记忆、敏感偏好、安全偏好等场景，MemOS 也获得了最高分。

MemOS 在个性化记忆管理、敏感偏好处理、遗忘机制等方面的表现都比较稳定。

**03 三项技术优化支撑了这次提升**

第一项是抽取上下文增强：不只对单个chunk进行抽取，而是在召回相关的上下文之后再一起抽取。

![](https://mmbiz.qpic.cn/mmbiz_png/VDCUoW3UiblK8TSibSNciawB6kdATpFxqGzQ6r6rBydKl1YETq95vsJcjyhZr6JKia5mDcEs75oKia4JHRAW2DiaS5siaDXWOkaLlAGhEPbTS5icznE/640?wx_fmt=png&from=appmsg)
第二项是时间理解能力提高：为相对时间生成标准化 timespec，检索时基于 timespec 进行时间渲染。

![](https://mmbiz.qpic.cn/mmbiz_png/VDCUoW3UiblKicV4MW9BhSLloGlicgxjeBnInAdK6RfrrmBuMpdcNicUaibLObTDkCUD7kAXZI16PJb8ibwIu61p2mLYBDsQvWaAnAgcgFbtFBy4o/640?wx_fmt=png&from=appmsg)
第三项，Evolve 链路优化：先轻量记录 Trace，再基于执行 DAG 切分成 Span，批量做压缩和质控。

![](https://mmbiz.qpic.cn/mmbiz_png/VDCUoW3UiblIGujrBXoic1E5h4Jf2TjuB9TMnQ9mz09jMO5cYnyZKtiavdgGh9YZLF8CMFQtL5TUCMm10SyNwH3zggyoVXaQVGVD5Sl0OjLzhQ/640?wx_fmt=png&from=appmsg)

## 看完这些，估计你已经想试了

接入的方式有两种，都比较简单。

**Agent 接入：安装一个插件就可以运行**

如果你在用 OpenClaw 或 Hermes，直接装插件。

插件会自动把记忆能力注入到Agent运行的过程中，不需要修改业务代码。

![](https://mmbiz.qpic.cn/mmbiz_png/VDCUoW3UiblLfWQ1XzBSEibNbxRn16l7hf5FeUxuyrkqXyDSWWKaM5Z32U9zDf7iaSOmFR3iaOzNy0SFj3ZaeWvsjAiaSZX2WiaSqCQzACPTrXnrc/640?wx_fmt=png&from=appmsg)
安装好之后重启，Agent 就会记住你的偏好了。

**代码集成很方便**

如果是自己开发的系统，用 HTTP API 或者 SDK 都行。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/VDCUoW3UiblKL1lHcCVfWwYC56oo6ia4ibEn7deHibO7lVCdIZu7GL4lC91okZug7uZgSe652kYu5BWBicd9SP20RBv9e0w5IIwia8vAX5Cb42x70/640?wx_fmt=png&from=appmsg)
保存对话、搜索记忆、更新偏好，也就是调用几个接口的事。

注册一个API Key，把环境变量设置好就可以调用啦。
