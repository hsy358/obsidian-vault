# Chinese-Jev：颜水成团队开源Jev闭环套件

Chinese-Jev 用一条统一管线，把散落在阅读、检索、评论、医疗、法律、金融的异构标注全部转成「候选集上的概率分布」，据此训出一个 322M 的轻量编码器，再按医疗/法律/金融三路独立微调，配套发布 30.8 万条留出评测集 CJ-Bench。经测试，其通用中文决策准确率 69.20%，反超闭源 Jev 的 68.35%，单次决策只要 14ms。

## 🎯 提出动机

Jev 这类 System One 模型专攻「只需决策、不需生成」的任务——路由请求、判断段落相关性、从候选集里选答案，输出有界，天然比反复调用大模型划算。但现有 Jev 的中文决策准确率明显受限，而已有的中文向发布面都很窄：QQwen3-1.7B-Jev 只做足球领域问答，MacJev 只做双语工具路由，通用中文决策能力尚无系统方案。更硬的障碍在数据：中文公开标注散落于阅读、检索、评论、医疗、法律、金融，而分类标签、命题判断、有序评分三种监督形态互不相同，无法直接拼在一起训练。

## 🛠 主要工作

1. **统一数据构造管线**：把所有异构标注统一转成「候选集上的概率分布」（choice / noul / score 三类决策，五条转换路线），再用决策级指纹去重——choice 候选排序后取指纹以对选项换序不变，目标一致留一条、冲突整组丢弃；同时强制同一源材料的样本落在同一划分，杜绝源级泄漏。最终得到 1000 万条通用语料（覆盖 8 大任务类别）、医疗 300 万、法律与金融各 2.4 万。
2. **轻量模型架构**：mmBERT-base + 2 层 Decision Transformer + 共享 scorer MLP，约 322M 参数。把类型、指令、全部候选、上下文拼成单序列并给每个候选插 marker，一次前向输出全部候选概率。
3. **两阶段训练**：通用语料训 1 epoch 得到 General，医疗/法律/金融各自独立从它出发训 4 epoch，架构与决策接口全程不变；目标函数 `L = L_CE + L_RL`（RLCD），交叉熵项天然吃软目标。
4. **评测基准 CJ-Bench**：307,900 条留出决策，同时评准确率、校准与时延；
5. **INT8 端侧部署方案**：量化后在 iPhone 15 Pro 浏览器内约 1 秒/次。

## 📈 性能

- 通用任务 **69.20%**，超过闭源 Jev 的 68.35%（相对 +1.24%）
- ECE 从 11.45% 降至 **3.78%**
- 单次决策 **14ms**，时延为托管 API 的 1/20.3
- 医疗 **87.65%** 反超 Jev 的 84.29%
- 三领域均值 70.82 达到 Jev 的 92.0%，每次决策仅 15ms
- 法律与金融仍低于 Jev，领域微调后的校准改善也不稳定
