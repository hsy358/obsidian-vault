## 一、产品介绍 🛠️

万有无界是一款面向团队和企业的**多 Agent 协作平台**，把你的需求拆解成不同任务，指派给不同的 Agent，最终交付完整解决方案。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/L3QFuGxENjeW2dzhrmlrbYuHGKJYBia2BNZe5TaL2lHldHWR2gudjms5zMaxuR25YRf9MWZdzInvIuFeOicZHSUicNeAAzticAy96zb37J2epd0/640?wx_fmt=png&from=appmsg)
整个平台围绕五个核心概念组织：

- **项目空间**：组织协作的容器，把群聊、成员、资产归拢到一个项目下
- **Agent**：在群聊里干活的角色，按职责接力
- **群聊**：最小协作单元，一个群对应一个具体任务
- **技能**：装到 Agent 身上的能力包，遇到匹配场景自动加载
- **资产库**：产出的文件自动沉淀在这里，随时可以找回
还有两个特殊角色，也是非常常用的助手：

- **小万**：你的个人助理，每个账号自动拥有，是平台的总入口。简单问题自己答，复杂任务帮你拆解、推荐专业 Agent、拉群协作。
- **小有**：项目管家，每个群聊创建时自动入驻、置顶。负责兜底路由消息、拆解任务树、盯任务推进、交付前核查产出。

## 四、核心功能 🔍

前面简单介绍了怎么使用

### 1. 单聊和群聊

**单聊**：单独和某个 Agent 对话，适合只用某一项能力、一问一答的场景。你还可以自己创建数字员工，三种方式：

- **快速招聘**：从模板选一个成熟 Agent，改个名字就能上岗
- **自定义创建**：自己起名、定职责、装技能
- **本地接入**：接入本机已跑起来的 Agent

![](https://mmbiz.qpic.cn/sz_mmbiz_png/L3QFuGxENjfaCXpN5l34icWLnA1TrSS0dwgahJOXdrGSN4ibic84SKPb7APKibck79sbvrOEfQPbqiczaPhz2no121L6dibolsjPkK5fJpicl2yxqU/640?wx_fmt=png&from=appmsg)
这里必须单独表扬一个设计：**自定义创建时的智能匹配技能**。你只要填 Agent 名称和职责，系统会自动推荐技能、默认全选，确认就能上岗。用户完全不需要理解「技能」这个概念，**这是整个产品里门槛降得最狠的一个设计**。

**群聊**：把多个 Agent 拉进同一个群，围绕一个任务接力配合。如果你目标明确，可以自己拉群；如果需求模糊，先找小万单聊，让它帮你判断该单聊还是群聊。

### 2. 项目空间

复杂的多人协作，可以用项目空间来管理：把相关群聊、成员、资产组织在一起。

两种创建方式：从模板创建（沿用预设的阶段、任务和 Agent 配置），或自定义创建。
![](https://mmbiz.qpic.cn/sz_mmbiz_png/L3QFuGxENjdy9XD9zbu44icsxCoSG62Ex4uRnMo4nF8BallmY30FkVIKa2nia2yLDdzLqlx57rc132ibIGZwSukoNcgHdiamyjNWFszD4tEmO8Y/640?wx_fmt=png&from=appmsg)

### 3. 技能市场

技能（Skills）是装到 Agent 身上的**领域 SOP 手册**。万有无界的技能市场有 **1 万款技能**，分类展示、可搜索，也可以发布自己原创的技能。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/L3QFuGxENjfUtuWRxb3Sz8kfHdyfHzBKxvrRzCOU8W1X3Is3PO1SbTepvMm4SO4sJpqOna2dKHMbzia8DDVZ1KFfj6AibjsWud6G1S5HDhvYU/640?wx_fmt=png&from=appmsg)
把实践沉淀成 skill，而不是每次让模型现想。

### 4. 资产库和知识库

工作过程中产生的文件会自动沉淀到资产库，分会话资产和项目资产，分类管理。你也可以主动上传个人文件到知识库，在任意对话中引用。

![](https://mmbiz.qpic.cn/mmbiz_png/L3QFuGxENjdIKMwSgY6P0RuLsuV4ugQN7QAruNXUfGkpHrXTY7Tp1PoibH60U0P81L4UETdVwf758Rb7mqhFu9f6kxMZuQl8zQnWomB1EGEE/640?wx_fmt=png&from=appmsg)

### 5. 多模型支持

万有无界接入了多家大模型，可按需切换：**千问、DeepSeek、GLM、Kimi** 都有。

注意：目前千问最高接入的是 Qwen3.7-Max，最新的 Qwen3.8-Max 还没接入，也不支持自定义模型。

## 五、和千问办公对比

很多人会有疑问，阿里有了“千问办公”，为何还要做“万有无界”？Chris 梳理了下，两者定位其实不一样：

维度

千问办公

万有无界

定位

通用型 AI 办公 Agent

多 Agent 分工协作平台

协作方式

工作台对话，一个 AI 大包大揽

主 Agent + 多专业 Agent 各司其职

适合人群

个人 + 企业

更偏团队和企业

模型支持

仅千问

千问、DeepSeek、GLM、Kimi 多模型

而且万有无界 6 月 30 日就内测了，**比千问办公（7 月 27 日内测）还早**。它补充了阿里 AI 办公 Agent 的产品矩阵，不过也不排除未来并入千问办公的可能。
