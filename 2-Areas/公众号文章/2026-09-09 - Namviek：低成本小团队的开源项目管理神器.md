# Namviek 的设计理念

Namviek 是一款为低预算的小团队量身打造的开源项目管理工具。它专注于提供项目管理的核心功能，并以易于使用、成本低廉为设计目标。无论你是开发者、创业者还是自由职业者，Namviek 都能帮助你更高效地管理项目，提升团队协作效率。

- 拥有开发技能的小团队：Namviek 基于开源技术，用户可以根据自身需求进行定制和扩展。
- 预算有限的团队：Namviek 提供免费的开源版本，无需支付任何费用。

# 技术栈

Namviek 使用了以下技术栈：

- Next.js: 用于构建前端应用程序，提供快速开发和性能优化。
- Node.js: 作为服务器端运行环境，提供灵活的开发能力。
- MongoDB: 用于存储应用程序数据，提供强大的数据库功能。
- Redis: 用于缓存数据，提升应用程序响应速度。

# 核心功能

Namviek 提供了一系列核心功能，满足小团队项目管理的基本需求：

- 任务管理: 创建、分配、追踪任务进度，并设置提醒。
- 项目管理: 创建项目、设置项目成员，并管理项目进度。
- 团队协作: 成员之间可以方便地沟通和协作，共享项目信息。
- 文件管理: 上传、存储和管理项目文件。
- 自定义字段: 根据项目需求添加自定义字段，提高项目管理效率。

# 如何使用 Namviek？

## 使用 Docker 部署

- 复制 .env.example 文件并将其重命名为 .env.local。
- 使用以下命令构建并运行容器：docker compose -f docker-compose.yml -f docker-compose.services.yml builddocker compose -f docker-compose.yml -f docker-compose.services.yml up

## 使用 Docker-Compose.services.yml 文件

对于开发者来说，docker-compose.services.yml文件可以帮助你轻松运行所有的服务（Redis、MongoDB、Minio）而无需在云端设置。你只需要安装 Nx 并运行代码库即可。

## 不使用 Docker 部署

你可以参考 Namviek 的设置指南，了解更多关于不使用 Docker 部署的步骤。
