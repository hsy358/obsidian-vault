# 25MB 搞定 100+ 种数据库：Rust 原生免装 Java，自带 MCP 还能让 AI 直接连库排查

> 来源：微信公众号「开源小聪明」，2026-10-03

## 摘要

**RBDC-MCP** — Rust 原生数据库连接中间件，25MB 自包含程序，支持 100+ 数据库类型，原生 MCP 协议让 AI Agent 直接连接数据库进行查询和故障排查。

## 核心技术亮点

### 1. 多数据库统一支持
- 支持 SQLite、MySQL、PostgreSQL、MSSQL 等
- 统一 API 接口，切换数据库只需改连接字符串
- 适合需要兼容多种数据库的 AI 应用场景

### 2. MCP 原生集成
- 内置 Model Context Protocol 支持
- AI 可直接调用数据库查询工具
- 应用场景：
  - **数据验证**："验证 /api/users/{id} 接口返回数据与数据库是否一致"
  - **SQL 注入检测**：AI 自动分析 SQL 安全性
  - **数据敏感性分析**：识别敏感字段，建议加密策略
  - **测试数据生成**：AI 自动生成 INSERT 语句

### 3. Rust 高性能
- 基于 Tokio 异步运行时
- 连接池复用，避免频繁连接开销
- 25MB 单文件，免装 Java（对比传统数据库工具）

### 4. 数据库间同步
- AI 自动生成 MySQL → PostgreSQL 同步脚本
- 处理数据类型差异
- 生成目标库 DDL

## AI 调试场景示例

```
开发者: "验证 /api/users/{id} 接口返回的数据是否与数据库一致"
AI 自动：
  1. 查询数据库中的用户数据
  2. 对比 API 响应格式
  3. 验证字段完整性
  4. 检查数据类型匹配
```

## 技术栈对照

| 特性 | RBDC-MCP | 传统方案（JDBC/ODBC）|
|------|---------|---------------------|
| 体积 | 25MB | 数百 MB（需装驱动）|
| 语言依赖 | Rust（无运行时）| Java / .NET |
| AI 集成 | MCP 原生 | 需自建桥接 |
| 数据库覆盖 | 100+ | 取决于驱动 |
| 部署 | 单文件 | 依赖环境 |
