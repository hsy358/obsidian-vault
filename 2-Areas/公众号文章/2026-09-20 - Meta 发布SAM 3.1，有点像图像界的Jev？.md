# Meta 发布SAM 3.1，有点像图像界的Jev？

Meta 把 SAM 3.1 接进了 Model API。给一张图或一段视频，再写一个对象名称，就能返回匹配对象的位置、像素区域，还能在视频里跟踪。

这次更新的是官方 API 接入，SAM 3.1 模型此前已经发布。

① **一句话选中一类对象**
比如写"yellow school bus"，找到黄色校车；写"glasses"，找到眼镜。返回的 Box 告诉程序对象在哪，Mask 则标出具体占哪些像素，后面可以接抠图、测量、局部编辑。

② **视频也能持续跟踪**
对象在画面里移动，程序可以按 ID 找到前后帧对应的区域。官方有第一视角分割双手的演示，Playground 也提供打码、聚光灯、运动轨迹等模板。模型给出区域，应用再实现效果。

③ **别人已经用来做什么？**
Conservation X Labs、Meta 等合作建设了野生动物视频数据集 SA-FARI，包含 11,609 段视频、99 个物种，提供框、分割掩码和跟踪标注。这是 SAM 3 的应用案例。

我看到这里也想到 Jev，哈哈。Jev 擅长对状态做分类、评分和是非判断，给程序返回结构化答案与概率；SAM 则把视觉对象变成程序能操作的区域。

相似的地方是把任务拆给专门的模型。需要理解复杂问题时，可以由多模态大模型先判断要找什么，再调用 SAM 去定位。官方 SAM 3 Agent 就展示了这种组合方式。

不过当前 API 每次只查一种概念，点选、框选等研究模型能力没有全部开放；否定句、复杂位置描述不稳定。对象离开画面或完全遮挡后，也不能默认跟踪 ID 一直有效。
