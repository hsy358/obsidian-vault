# 近期看过最有意思的的 JEV 模型应用场景！

分享几个最近看到：关于 Jev 模型很有意思的开源项目：
🤖 Agent-Beacon
Jev 让大规模的评估和分类变得可行，而开源项目 Beacon 是一个能够自我改进的 Agent 内存管理层，能够收集不同工具的任务执行数据，将运行经验沉淀下来，提供给 Agent 使用；
⭐️ 在收集过程中，其将大量的 Agent 会话，批量提供给 Jev 模型做快速打分评估，判断会话是不是有价值的工作流，过滤掉低质量的噪声；

🤖 HarnessRouter
HarnessRouter 能够帮助用户选择最适合任务的 Harness 框架：其定义了统一的协议，让所有 Agent 框架都能以一套统一的接口对外提供服务，支持随时快速切换；
⭐️ 而其最重要的自动路由能力是结合了 Jev 模型，让其对用户 Prompt 结构化分类，从而提交给不同的 Harness 框架；
- 此外，HarnessRouter 还集成了「System One Harness」，专门用来完成决策任务；

🤖 Pg-Jev
Jev + 数据库的最佳实践！Pg-jev 作为 PostgreSQL 的扩展插件，直接将 Jev 模型融入到了 SQL 中，支持在 Where 等子句中使用，能够实现对数据库里的每一行数据进行逻辑判断；
⭐️ 传入一行记录 + 自然语言判断条件，能够得到一个置信度概率分数，能够快速判断某一行数据是否符合规则，可以替代掉开销巨大的向量相似度判断；

🤖 AnyJev
无需重新微调训练，就能将任意的开源大模型，转换为 Jev 风格的「结构化决策模型」，不再进行大量文本生成，专门完成选择，评估打分，标签分类等任务；⭐️ 一次前向传播过程中，只需要读取候选 token 的概率分布，不需要进行解码，大幅降低推理延迟；
- 并通过「只提供选项，提前获取模型对于选项先验概率」和「循环轮换选项位置」，消除传统 LLM 对于特定选项和位置的偏好；同时，支持利用少量实际标注信息，校准最终置信度；
