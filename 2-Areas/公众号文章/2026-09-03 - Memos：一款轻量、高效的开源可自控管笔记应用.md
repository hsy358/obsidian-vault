# Memos：一款轻量、高效的开源可自控管笔记应用
你是否厌倦了笔记应用的隐私担忧和数据锁定？你是否渴望一款轻量、高效、且完全掌控在自己手中的笔记工具？今天，我们将为你介绍一款开源、自托管的笔记神器——Memos，它将彻底改变你记录和管理信息的方式！

**Memos：重新定义你的笔记体验**

Memos 是一款基于 Go 和 React.js 开发的开源笔记应用，它致力于提供一种简单、高效、安全且可定制的笔记体验。不同于市面上那些依赖云服务的笔记应用，Memos 将所有数据存储在你的本地数据库中，让你完全掌控自己的信息安全。

**无与伦比的隐私保护：你的数据，你做主**

在信息安全日益重要的今天，数据隐私已成为人们关注的焦点。Memos 秉承“你的数据，你做主”的理念，将所有运行时数据存储在你的本地数据库中，彻底消除数据泄露的风险。这意味着，你的笔记、你的想法，永远属于你，不受任何第三方干预。  你可以安心地记录你的想法，工作计划，或者任何你想要保存的内容，而无需担心隐私问题。

**极致的书写速度与效率：轻量级下的强大功能**

Memos 采用简洁的纯文本编辑方式，并支持强大的 Markdown 语法，让你能够快速记录想法，并轻松地进行格式化。无论是简单的待办事项，还是复杂的文档撰写，Memos 都能轻松胜任。其轻量级的架构保证了极快的启动速度和流畅的运行体验，让你可以专注于写作本身，而不是被工具所束缚。

**高度可定制：打造专属笔记风格**

Memos 提供了丰富的个性化定制选项，你可以根据自己的喜好调整服务器名称、图标、描述、主题等，打造独一无二的笔记风格。  你还可以自定义执行脚本，进一步扩展 Memos 的功能，使其更好地适应你的工作流程和个人需求。这不仅仅是一个笔记应用，更是一个可以根据你需求不断演进的工具。

**一分钟部署，轻松上手：Docker 助力无缝安装**

Memos 支持 Docker 部署，这意味着你可以通过简单的命令行指令，在几秒钟内完成安装和部署。  对于熟悉 Docker 的用户来说，这将是一个无比便捷的过程。即使你不是 Docker 的专家，我们也提供了详尽的文档，指导你完成整个安装流程。

```
docker run -d --name memos -p 5230:5230 -v ~/.memos/:/var/opt/memos neosmemo/memos:stable
```

(注意：此命令适用于 Unix/Linux 系统。Windows 用户请参考详细文档。)
