# 不到 30MB， 纯 Rust 写的 GIS 更香了 。
大家好，我是熊叔，今天我们继续逛 GitHub。

搞 GIS 的朋友，大概都受过这两头气：

商业软件很好用，但是授权费很高，并且只认 Windows；开源的QGIS是免费的，但是换台电脑配置环境，Python 和 GDAL 稍微有点不兼容就折腾半天。

最近在 GitHub 上看到了一个很有雄心的开源项目，想要把这两个问题一起解决掉。

它叫 **RustGIS**，全部用 Rust 写的。

![](https://mmbiz.qpic.cn/mmbiz_jpg/VDCUoW3UiblKem6CatzV6lvMTY0hrIPpxhMSueQ6G1oBbV1Paiaibyw5UjsRQqnPCCKYY1c8NuLkydRB5DXB5AWuhicfHtBFvicKkib7JKdm5jPJU/640?wx_fmt=other&from=appmsg&watermark=1#imgIndex=0)

**简单说，它就是一个免费、开源、能跨平台的现代化桌面 GIS。**

支持Windows、Mac、Linux，也可以运行在浏览器上。

界面抄了 ArcGIS Pro 的作业：Ribbon 工具栏、左边的图层树、底部属性表都在老位置，ArcGIS Pro 老用户可以直接用肌肉记忆来操作，上手成本几乎为零。

![](https://mmbiz.qpic.cn/mmbiz_png/VDCUoW3UiblJdicsRBib0GKPjNGhgp6Qy966XibboHtvk3GqP3PSxXybVZrIw7uKiaXibDE3qianGIEWVDNwnX4DJ2qjsApajhvmW7f7HaU2GLuh6Q/640?wx_fmt=png&from=appmsg&watermark=1#imgIndex=1)

## 拿一个真实场景走一遍

实不实用，直接拉个典型需求开刀：**在地图上找到非洲人口最多的五个国家，并画出300公里的缓冲区。**

以前的方法很繁琐：打开属性表、排序、按住Ctrl键手动多选。

加载好自带的 World Atlas 数据之后，在 RustGIS 中打开AI面板，然后输入一句话：

> 帮我找出非洲人口最多的五个国家。

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/VDCUoW3UiblI193eke1yNpV3FE8BSE9UDEfTZwYd4UdZ9zLCelxbHQeQIz9ptEyTWv3RPsPbQ700hN0f1eQhqv5CdeakJvbSujYticOHicCqmE/640?wx_fmt=other&from=appmsg&watermark=1#imgIndex=2)

说完之后就马上在后台读取属性表，并把前五名圈出来。

镜头自动对准非洲，高亮、配色、标注等也一并调整好，不需要我手动去翻菜单。

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/VDCUoW3UiblImBp6VJo7QzeHL1ufk1icp68Tl9oylo5zicf7cWw0N5yLcoC0E6m8j4TeLQrgR4sjUicNK2V1XMZeCsJLDy1Awelc949faia0WibQ8/640?wx_fmt=other&from=appmsg&watermark=1#imgIndex=3)

再加上一句做300公里缓冲，后台跑完空间分析后，直接生成了新的图层，底图一点也没有改变。

![](https://mmbiz.qpic.cn/mmbiz_jpg/VDCUoW3UiblIRIyaMFqfXY8dMrsicsrAUtXnLk2UfxFz4k9DSQo50VOReavCmm3hniaOEaIyfK63lJOcuuz2guHg7gGibibqLoMwibfwLgjm0fugE/640?wx_fmt=other&from=appmsg&watermark=1#imgIndex=4)

整个过程就是动动嘴皮子说了一句话，剩下的脏活累活全被它包圆了。

## 有人可能好奇，它到底是怎么做到的？

其实它的底层设计就是一句话：点击就是一条带编号的命令。

点击按钮就等于是执行了一条命令。反过来，按照顺序重新播放这串命令，就可以实现像素级的重现操作。

**01 一切皆命令**

Ribbon 上的每一个按钮都有一个唯一的 ID。在终端上输入 `rustgis-cli commands`可以查看所有的命令和参数，软件自带可执行说明书，可以随时一键重现。

![](https://mmbiz.qpic.cn/mmbiz_png/VDCUoW3UiblJHlIFfxowUqXkI19x5jtEiaWtV90uZ9ygvY2rMX98Fz3wrE5bx5r0b5Plnf1Tc2PHXKIRkuvtx0mj3L9fJkWHCfHk3SkTFaD2s/640?wx_fmt=png&from=appmsg&watermark=1#imgIndex=5)

02 桌面三端、纯网页版

桌面端就是单个文件，双击就可以打开，不需要担心依赖冲突的问题。作者也编译了WebAssembly版本，在浏览器中直接运行，实现了真正的零安装。

03 自带AI，还可以被外部AI调度

侧边栏的助手可以真正选择和调整样式，并且可以本地运行 Ollama 离线版，甚至内嵌了 MCP 服务。像 Cursor、Claude Code 这样的外部 AI 工具可以直接调用它来做地图操作。

![](https://mmbiz.qpic.cn/mmbiz_png/VDCUoW3UiblJP0CS18XHj77wISLVFMpuLBJJ56BM3o7MCXrIPnqckSwwhfuDwzkrQNKF7FibHDHM0pbm8uiad49asTqBBV3lAKanntLqEYlWew/640?wx_fmt=png&from=appmsg&watermark=1#imgIndex=6)

**04 一千多个工具，格式全通**

除了常规分析之外，还集成了 GeoLibre 和 Whitebox 工具箱，1000多个空间算子包括了水文遥感；格式有Shapefile、GeoPackage等，还可以读取 LAS 激光点云。

## 想试的话，装起来很简单

最方便的是网页版，在浏览器中打开即可 `web.rustgis.app` 就可以用了；Python党也有现成的在线Google Colab示例。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/VDCUoW3UiblIHzFJMLAEVL7oibND3Hqic2hyTQ74boiaukhqkhac9rJVLwtPDTrk8picXFJVWOyeKXiaSXGE6wH5dGhPAVWeNPxeD8zJg3VLIpAZA/640?wx_fmt=png&from=appmsg&watermark=1#imgIndex=7)

Windows 用户只需要执行一条命令就可以完成：

```
POWERSHELLwinget install OpenGeos.RustGIS
```

macOS 用 Homebrew，Linux 用 AUR。想要源码的，安装好 Rust 1.90 以上版本就可以运行 `cargo run` 就行。

![](https://mmbiz.qpic.cn/mmbiz_png/VDCUoW3UiblLy3M00eP8RUYqhzMO0HibI38sTcUxZLdg0Q5S89tUiapU5W00nEZmgsol0fPAkpw5jYRiaCFAxWSRMfPH1x0Q1zL2gxRKZQL2ROM/640?wx_fmt=png&from=appmsg&watermark=1#imgIndex=8)

## 到这里边界也给大家提提

新项目才刚开始，大家尝一尝就好，不要一激动就直接把代码推送到生产环境里。

我归纳出四个原因供大家参考：

- 长期稳定性和极限性能尚未在大项目中得到验证。
- 数据库只支持 PG 和 DuckDB，且 PostGIS 桌面端仍处于只读状态。
- 顶点捕捉编辑、复杂空间连接等高频操作还在路线图里排队。
- 插件生态也才刚起步。
所以现在做一个轻量级的原型工具比较合适。
