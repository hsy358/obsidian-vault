# Pi 1.0 正式发布：一个更硬核、更极简、真正可扩展的 AI Agent 底座

> 注：本文是今天第二篇关于 Pi 1.0 的微信文章（第一篇：OwF_IZlGzQQ9llZ80M6CwQ），本篇侧重项目背景与收购故事。

## 核心信息（来自网络搜索补充）

### 收购背景
- **Pi 最初作者**：Mario Zechner（libGDX 作者，也参与过 OpenClaw）
- **2026 年春**：项目被 **Earendil Works** 收购
- **Earendil Works 创始人**：
  - **Armin Ronacher**（Flask 作者，曾任 Sentry 工程负责人）
  - **Colin Daymond Hanna**
- Mario Zechner 成为股东，继续主导技术方向
- npm 包从 `@mariozechner` 命名空间迁移到 `@earendil-works`（从 v0.74.0 开始）

### Pi 1.0 发布成绩
- 迅速登顶 **Hacker News**，突破 **1000+ points**
- 同时发布 **Pi Durable**：面向长时运行 AI Agent 的实验性框架

### 技术关系
- **OpenClaw**（Peter Steinberger 创建）基于 Pi 构建
- Pi 是 OpenClaw 的底层 Agent 执行器
- 这也是为什么 OpenClaw 和 Pi 有很深的渊源

### 关键定位
- Pi = 极简可扩展的 Agent harness（不是框架，是外壳）
- 所有功能外置，核心极简（4 个工具 + 热重载扩展）
- "Agent 适应你的工作流，而不是反过来"
