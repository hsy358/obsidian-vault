# 豆包/千问/元宝，集体转向 Personal Agent

> 来源：产品笔记（微信公众号），授权转载至人人都是产品经理
> 原文：https://mp.weixin.qq.com/s/5gu5fWceXAuRnG8SJ8nCwA

## 核心摘要

国内前四的通用型AI助理里，除了DeepSeek，豆包、千问、元宝正集体转向Personal AI Agent。

**本质**：从ChatBot → Agent → Personal Agent的演进路径。三大厂的切入方式完全不同。

---

## 1 豆包小豆

- **代号**：Spell，原个人AI助理项目，4月开始内测
- **工期**：6天（中秋3天加班，9月30日拿出内测体验版）
- **产品名**：小豆（非小度），可能独立APP，也在豆包主APP中使用
- **策略**：基于已有积累（豆包手机助手）整合，不是从0到1

> 字节做Personal AI Agent有深厚积累：豆包手机助手团队本来就在做手机端Agent。

## 2 千问 Personal Agent

- **定位**：把自己定位为Personal Agent，不是重做产品
- **核心**：构建全域、终生的Context
  - 通用Context：围绕用户身份（学生、职员、父母等）
  - 领域级Context：理财、学习、健康、购物、生活服务、工作等场景
  - 多终端Context：眼镜、穿戴设备等
- **节奏**：未来几个月推出统一Personal Agent，加速与生态伙伴合作

## 3 元宝 Personal Agent

- 还在评估：新增模块 vs 独立产品
- 基础：模型能力 + 通用AI助手积累
- 观点：个人智能体核心比拼的不是模型能力，而是服务宽度和深度

---

## 集体转向背后：Personal Agent 6大特征

| # | 特征 | 说明 |
|---|---|---|
| 1 | 围绕个人 | 自主办事，关键节点由人确认 |
| 2 | 独立云端VM | 后台24小时持续运行 |
| 3 | 链接生态 | 链接生活里各种日常服务 |
| 4 | 长期记忆 | 长周期任务跟进 |
| 5 | 多端接入 | 多入口，多终端 |
| 6 | 安全可控 | 用户愿授权 |

---

## 核心观点

> Agent发展到Personal阶段，比拼的已不是模型能力，甚至不是工程能力。
> 而是**服务能力，链接生态的能力，理解真实用户生活需求的能力**。
> 三分靠模型，七分靠应用。

这是纯消费级C端产品，围绕个体用户生活状态进行——和之前AI办公Agent围绕任务进行，是两个方向。也是更具想象力的方向。
