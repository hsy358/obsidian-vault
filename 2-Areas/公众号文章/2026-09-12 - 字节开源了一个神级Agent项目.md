# 字节开源了一个神级Agent项目

字节跳动刚开源了个叫 OpenViking 的项目，专门治 AI Agent 的"失忆症"。

以前 Agent 聊完天就忘事，跨会话全得从零开始。这次它直接给 AI 装了个"文件系统"，把记忆、文档和技能全塞进虚拟目录里统一管理。

最狠的是三层加载机制。它把上下文分成摘要、概览和详情三层，按需调取。实测 Token 消耗能降六到八成，复杂查询的命中率还提了约四成。而且检索过程全透明，哪一步错了一眼就能看出来。

部署也不折腾，一条 Docker 命令起服务，还能直接接 Claude Code 等主流工具。说白了，就是让 AI 不仅能记住，还能像人一样翻资料、攒经验。
