## 什么是 Higress？

Higress 是一款**云原生 API 网关**，源自阿里巴巴内部电商、交易等核心生产场景的实践沉淀。它的核心理念很简单：

> **三合一架构**：流量网关 + 微服务网关 + 安全网关

基于 **Envoy + Istio** 构建，遵循 Ingress/Gateway API 标准，Higress 不是简单的功能堆砌，而是从架构层面重新思考网关应该是什么。

### 核心能力一览

能力维度

功能描述

**流量网关**南北向流量入口，服务暴露、路由转发

**微服务网关**东西向服务治理，Nacos 服务发现、Sentinel 限流

**安全网关**WAF 防护、认证鉴权、限流降级

**AI 网关**大模型 API 统一接入、Token 限流、内容安全

## 为什么选择 Higress？

### 1️⃣ 性能碾压：Wasm 插件，3 倍于 Spring Cloud Gateway

传统微服务网关如 Spring Cloud Gateway 基于 JVM，虽然生态丰富，但性能瓶颈明显。

Higress 采用 **Wasm（WebAssembly）插件系统**，将插件运行在沙箱环境中：

- • **性能对比**：相同场景下，Higress Wasm 插件的性能是 Spring Cloud Gateway 的 **3 倍**
- • **运行时升级**：从 V8 切换到 **WAMR（WebAssembly Micro Runtime）**，开启 AOT 模式后，大部分插件性能提升 **50%+**，复杂逻辑插件性能**直接翻倍**
- • **毫秒级热更新**：规则变更无需重启，秒级生效

### 2️⃣ AI 原生：专为大模型时代设计

2024 年 v1.4 版本发布，Higress 正式开放 **AI 网关能力**，这是目前开源网关中少有的 AI 原生设计：

```
✅ 支持 100+ 主流大模型统一接入✅ 多模型统一路由与协议转换✅ Token 级精细限流✅ 语义缓存，降低调用成本✅ 内容安全防护（提示词攻击检测、敏感内容识别）✅ 智能工具路由（MCP Server 支持）
```

想象一下这个场景：你的应用同时接入了通义千问、GPT、Claude 等多个大模型服务。Higress 可以：

- • 自动屏蔽不同厂商的鉴权差异和接口差异
- • 实现多模型容错切换（一个挂了自动切另一个）
- • 基于 Token 用量精准限流，避免账单爆炸
- • 对 LLM 输出内容进行安全审核
这些能力，全部在网关层统一治理，后端服务无需任何改动。

### 3️⃣ 生态集成：开箱即用

Higress 深度集成 K8s 和微服务生态：

- • **Nacos**：服务发现与配置管理
- • **Sentinel**：限流降级
- • **K8s Ingress/Gateway API**：标准化配置
- • **Prometheus + Grafana**：可观测性
- • **Nginx Ingress 兼容**：迁移成本极低

### 4️⃣ 扩展性强：自定义插件

通过 Wasm 插件系统，你可以用 **Go、Rust、C++** 等语言编写自定义插件，30 行代码即可实现一个完整的插件逻辑。

而且 Higress 近期还开源了 **Plugin Server**，解决了私有化部署时插件拉取的痛点。

### 场景一：微服务架构统一入口

