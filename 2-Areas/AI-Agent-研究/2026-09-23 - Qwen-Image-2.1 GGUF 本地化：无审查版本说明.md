# Qwen-Image-2.1 GGUF 本地化

**官方模型**: Qwen/Qwen-Image-2.1
**无审查 GGUF**: abenzerps/Qwen-Image-2.1-Uncensored-GGUF / KasugaiSakura/Qwen-Image-2.1-Uncensored-GGUF
**发布时间**: 2026-09-21

## 关键澄清："无审查"是什么？

> ⚠️ **事实**：原版 Qwen-Image-2.1 **模型本身没有内置安全过滤**，_pipeline 文件里 5 个组件（processor / scheduler / text encoder / image transformer / VAE）无一 是 safety checker。

"无审查"实质：
- **官方 Demo** 不在 Space 里跑模型，而是调阿里云 API → API 层做内容审核
- **本地 GGUF** 跑在你自己机器上，API 层过滤不存在，直接出图

所以不是"移除过滤层"，而是"本来就没有，走本地就不经过 API"。

## 技术规格

**架构**: 图像 transformer + Qwen3-VL text encoder + VAE

| 文件类型 | 量化精度 | 体积 |
|---|---|---|
| Transformer GGUF（推荐 Q4_K_M） | Q4_K_M | ~4.6 GB |
| Transformer GGUF | Q6_K | ~5.9 GB |
| Transformer GGUF | Q8_0 | ~7.6 GB |
| Text Encoder | BF16 | 16.3 GB |
| Text Encoder | Int8（优化） | 8.7 GB |
| VAE | BF16 | 644 MB |

推荐 **Q4_K_M**（体积 / 质量最佳平衡）。

## 使用方式

需 **ComfyUI + ComfyUI-GGUF** 插件，典型目录结构：
```
ComfyUI/models/
├── diffusion_models/
│   └── qwen-image-2.1-Q4_K_M.gguf
├── text_encoders/
│   ├── qwen3vl_8b_bf16.safetensors
│   └── qwen3vl_8b_int8_convrot.safetensors  # 可选 Int8 版
└── vae/
    └── qwen_image_2.1_vae_bf16.safetensors
```

## 对 OpenClaw / 德勤项目的意义

- 当前 OpenClaw `image_generate` 工具调用云端服务（受 API 审核限制）
- Qwen-Image-2.1 GGUF 本地跑在 **ComfyUI** 上
- 可探索：OpenClaw → 本地 ComfyUI API → Qwen-Image-2.1 GGUF 的生图管线
- 适合需要**快速/低成本/隐私**生图的场景（不出图不经过外部 API）
- 注：当前主机无 GPU（3.6GB RAM），无法实际运行
