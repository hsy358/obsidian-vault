## 📊 图的内容结构

| 区块 | 位置 | 内容 |
|---|---|---|
| **顶部标题** | 顶部 | 产品名 + 四字核心卖点 + 资料来源 |
| **图例** | 标题下 | ★ 关键模块标记说明 |
| **AIP 层** | 第 1 层 | 建模助手 ★ / 受治理查询 / 受治理更新 |
| **应用层** | 第 2 层 | 工作区视图 / 协作流程 / 工作流 / 自动化 / 动作入口 ★ |
| **定义层** | 第 3 层 | 7 个 Schema 模块（含 Function ★）+ 计算公式 + 页面布局 + 记录类型 |
| **存储层** | 第 4 层 | 图数据库 ★ / 列式存储 / 存储协同 |

| **原则条** | 最底部 | 「先表达清楚 → 围绕它运行 → 持续反馈」 |

## 🎯 关键模块（★ 标记）

1. **建模助手**（AIP 层）— AI 介入 Schema 定义的关键入口
2. **动作 / 业务入口**（应用层）— 用户与本体交互的唯一接触面
3. **Function**（定义层）— 配置无法表达时的"逃生舱"，平衡灵活性与治理
4. **图数据库**（存储层）— 关系遍历能力的物理基础
