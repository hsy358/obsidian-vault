## 🚧 部署过程踩坑

### 坑 1：GitHub 仓库下载卡死
- `git clone` 报 `GnuTLS recv error (-110)`
- `codeload.github.com` zip 下载被截断（3.4MB 截断到 280 文件）
- **解法**：用 Contents API + git_trees recursive 拿到完整文件树，再批量 base64 解码下载（最终 326 文件 / 7.7 MB）

### 坑 2：Docker build 卡 apt-get update
- `docker compose build web` 卡在 `apt-get update` 6+ 分钟
- buildkit 内 apt-get 拿不到数据（阿里云镜像在 buildkit 网络里不通）
- **解法**：放弃 docker 容器跑 web，改用**本地 Python venv + 单独 docker mongo/redis**

### 坑 3：MiniMax 没有 OpenAI 兼容端点
- `https://api.minimaxi.com/v1/chat/completions` → 404
- 只有 `https://api.minimaxi.com/anthropic/v1/messages` → 200
- **解法**：走 TradingAgents 已有的 `ChatAnthropic` provider 代码路径，通过 sidebar 暴露 anthropic 选项

### 坑 4：TradingAgents 没有 minimax provider
- jesse1106 中文版 `.env.example` 里有 dashscope/deepseek/openai/openrouter/google/anthropic/siliconflow/custom_openai/qianfan，**但 UI 没暴露 anthropic**
- 代码（`trading_graph.py` 第 115 行）支持 `llm_provider="anthropic"` 调用 `ChatAnthropic`
- **解法**：手动加 anthropic 选项到 UI（37 行 sidebar.py + 11 行 analysis_runner.py 改动）
