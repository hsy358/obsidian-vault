## 1. SCQA 主线

### Situation（情境）

- 中国 AI 自 2024 年以来发生剧变：5.15 亿 GenAI 用户（人口渗透 36.5%）
- 备案 GenAI 服务从 302 增至 868（YE 2024 → Apr 2026，约 2.9 倍）
- AI 核心产业规模破 1.2 万亿元；30%+ 大型制造商已应用 AI

### Complication（挑战）

- 这不是单一技术事件，而是消费端 / 企业端 / 产业端**生态系统同步加速**
- 但企业内部变革滞后：60% 企业仍处于理解 / 评估 / 试点，仅 18% 进入核心业务集成
- 真正的护城河已从模型层移到企业 Context + Integration + Execution

### Question（关键问题）

**LELI China 应该从哪里开始行动？**

### Answer（答案 · 3 大判断）

1. **中国走自己的 AI 路径**——不是照搬剧本，而是基于开源、快速实验、制造深度与业务整合形成独特生态
2. **中国独特优势**是速度 + 规模 + 市场整合 + 业务实验的组合，技术→业务的回路更短
3. **AI 正从生产力工具走向工作流、决策、软件开发与组织设计**——管理问题不再是"AI 能否有用"，而是"企业内部应当如何变革"

## 3. 主线叙述（5-9 句话）

1. **2024-2026 斜率至关重要**——用户、服务、企业、工厂四股力量同步加速，形成生态系统级拐点
2. **中国的 AI 优势是更短的商业学习循环**：发现问题 → 构建原型 → 部署 → 收集反馈 → 再次迭代，闭环周期远快于技术发布
3. **AI 已嵌入中国 8 大运营场景**（客户、销售、供应链、制造、财务、税务、物流、员工工作），从附加软件走向运营底座
4. **开源模型让实验不再奢侈**——10B+ 下载、Hugging Face 中国模型占比 41%，企业无需等待完美平台即可启动
5. **60% 企业仍处早期，18% 已突破至核心业务**——前沿从 chatbot 迁移到 workflow execution
6. **制造业是另一层**：Physical AI 把感知 → 决策 → 行动 → 反馈闭环嵌入物理操作系统（中国占全球新工业机器人 54%）
7. **企业内部 5 阶段跃迁**：Copilot → Agent → Workflow → Process Redesign → Organization Redesign
8. **模型会普及，Context + Integration + Execution 才是护城河**——12 类企业核心资产决定 AI 价值转化
9. **5 大行业实证已经发生**：Finance Agent（自动报告 + 差异分析）、Tax Agent（合同理解 + 风险预警）、Proactive Insight（主动监测）、AI Coding（43%+ 代码 AI 生成）、Manufacturing（99.98% 检测准确率）
10. **LELI China 的 8 步行动**：识别高价值用例 → Copilot 到 Agent → 重设计工作流 → 构建企业 Context → 平衡全球标准与中国速度 → 建立 AI Coding 治理 → 衡量业务价值 → 管理两类风险
11. **三大判断 + 一个挑战**：中国走自己的路径；独特优势是速度 × 规模 × 整合 × 实验；管理挑战是在 Global Governance × China Speed × Enterprise Redesign 三股力量间取得平衡，同时管理"行动风险"与"不行动风险"
