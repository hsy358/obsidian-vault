## 一、岗位本质拆解（一句话）

这不是"大模型应用岗"，是 **"车端 Agent 云端中台岗"**：
端侧跑 Agent（车机本地推理），云端跑 **Skill 提示词管理 / Tool 服务 / 并发调度 / 上下文存储 / 数据埋点回流 / 场景引擎**——
本质是 **"AI 编排平台 + 高并发调度 + 业务中台"三合一**，前端也要写（场景引擎、推荐服务带 UI）。

技术栈画像：**Java/Kotlin (Spring Boot) 为主干 + Python (LangChain/LangGraph) 做 Agent 层 + MySQL/Redis/Kafka 数据层 + TS/React/Vue 前端**。

## 三、这张牌怎么打（针对岗位的叙事重构）

**不要**用"金融科技交付负责人"开场，要用 **"Agent 平台 + 高并发中台 + 业务场景落地"** 三段式：

1. **Agent 工程化**：guyu = 平安版 Coze。Skill（Prompt 版本化/A-B/工具注册）+ Tool 服务（工具异常兜底）+ Memory/上下文 + Trace 全链路 —— **直接对应 JD 第 1、5、7 条**
2. **并发与调度稳定性**：Agent 平台是多租户多 BU 并发 + 工具调用超时/失败回退 + Rerank 延迟治理 —— 对应 JD 第 2 条；用"降级/限流/回退"语言替代"并发数"
3. **数据层与埋点回流**：知识库 QA 抽取 → 向量化 → 混合检索 → Rerank → 命中/可信度日志 → 运营反馈闭环 = **现成的埋点与数据回流范式**；数据中台 = 治理工程 —— 对应 JD 第 3、4 条
4. **场景引擎**：惠企平台"政策标签化 + 条件结构化 + 审批流自动流转 + 兑现进度可视化" = **场景引擎的通用范式**（规则引擎 + 流程引擎 + 进度可视化）—— 对应 JD 第 6 条
5. **前后端**：Vue 场景引擎控制台 / 进度看板经验 —— 对应第 6 条"包含前端与后端"

## 四、面试必须准备的 6 个硬问题（按岗位定制）

1. **座舱 Agent 的端云职责怎么切？**（云端做 Tool/编排，端侧做感知/低时延；记忆与上下文的端云同步）——用"平安版 Coze 的端侧不可用时纯云降级"逻辑答
2. **多任务高并发下怎么保时延？** → 分级：实时交互（同步/流式）、准实时（异步队列）、离线批处理；令牌桶限流 + 优先级队列 + 大模型超时熔断 + 降级模板答案
3. **Tool 服务怎么设计？** → 统一注册表 + schema 契约 + 超时/重试/幂等 + 工具异常不阻断主链路（guyu 的失败回退）
4. **上下文 / 记忆 / KV 存储怎么治理？** → 短期会话态（Redis）+ 长期记忆（向量库）+ 业务数据（SQL），对齐 JD 第 4、5 条
5. **埋点与数据回流怎么打通端云？** → 统一 event schema → 采集 SDK → Kafka → 数仓 → 归因分析 → 回流训练/策略更新（结合数据中台 + Kettle 经验）
6. **LangChain/LangGraph 落到高并发生产环境的坑** → 你有真坑可讲：Embedding 服务 `cuda:0` 硬编码、LangChain 0.1→0.2 API 变更、Pydantic v1→v2 schema 迁移、Prompt 注入防御、Token 预算控制
