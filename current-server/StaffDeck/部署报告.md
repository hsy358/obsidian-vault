## ⚠️ 踩到的 1 个坑 + 修复

### 坑 1: Node.js not on PATH（systemd user service）

**现象**：
```
error: Node.js is not available on PATH
error: Node.js is not available on PATH
... (重复 8 次)
```
service 一直 `auto-restart`，Tasks 升到 20 后 700MB 内存

**根因**：
- Node.js 装在 nvm (`/root/.nvm/versions/node/v22.23.1/bin/`)
- systemd user service 启动时不加载用户 shell profile → PATH 找不到 node
- `dev_supervisor.py` 启动时 `validate_prerequisites()` 调 `shutil.which("node")` 失败 → raise RuntimeError

**修法**：
service file `Environment="PATH=..."` **必须显式**包含 nvm bin 路径：
```ini
Environment="PATH=/root/projects/staffdeck/backend/.venv/bin:/root/.nvm/versions/node/v22.23.1/bin:/usr/local/sbin:..."
```

**永久规则**（已加入 MEMORY.md 范畴）:
- ✅ systemd user service 调 Node/Python/npm/pnpm 必须在 Environment 显式声明路径
- ✅ 改完 service file 必跑 `systemctl --user daemon-reload` 再 restart
