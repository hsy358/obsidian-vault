# 灵·洞本体工作站 V1 — 部署可行性评估

## 一句话结论

**✅ 技术上能部署，但 3 个硬性约束必须何大人决策后才能动**：
1. 这版本是 **`RELEASED_WITH_UAT_WAIVER`**（真人 UAT 未执行）—— 不是生产就绪
2. **GPL-2.0 强传染** —— 商业项目（含德勤咨询交付）不能直接闭源用
3. **与"AI Native Agent 平台"赛道弱相关** —— 这是底层"语义治理 / 本体建模"工具，不是 Agent 平台本身

## 3. 3 个硬性约束

### 约束 ①：版本成熟度

> 官方 README 第 1 段写明：
> "V1 为 `RELEASED_WITH_UAT_WAIVER`：机器可执行门禁已形成，但真人 UAT 明确记录为 `NOT_EXECUTED`。"
> "本仓库不代表生产上线批准、安全认证、等保/密评结论或高可用承诺。"

**含义**：可以"试"，不能"用"（任何生产/客户/德勤交付场景）。

### 约束 ②：许可证传染

`GPL-2.0-only` —— 商业咨询交付若涉及客户代码、敏感数据治理、有合同约束的场景，**强行集成 GPL 组件 = 必须开源衍生作品**。

**对德勤场景的影响**：德勤内部若有"AI Native Workspace"涉及客户数据本体建模，GPL-2.0 风险评估要专门过 IP/Legal。

**例外**：纯研究 / 个人学习 / 内部 Demo / 自行开发不发布 —— 风险小。

### 约束 ③：当前服务器资源紧张

当前已跑 30+ 容器（Dify + RAGFlow + Langfuse + AgentTeams + Milvus + Neo4j 等）。

本体工作站生产模式额外需要：
- Postgres 17：~2 GB
- Java API：~3 GB
- Studio Web：~1 GB
- Caddy：~256 MB
- **合计 ~6.25 GB** → 加上现有 21 GB ≈ **27 GB / 30 GB**，留给 OS / cache 的余量很小。

## 4. 部署路径（如果何大人决定装）

### A. 最小试水路径（推荐先做这个）

**目的**：跑起来看看产品长什么样，10 分钟搞定。

```bash
cd /root/projects
git clone --depth 1 https://gitee.com/lucas_YIN/ontology_platform.git ontology-studio
cd ontology-studio
npm install --prefix studio-web
npm run dev:local
# → http://localhost:3100  (Web)
# → http://127.0.0.1:8080/api/v1/health  (API)
```

**无需 Java 24、无需域名前置**——Docker Compose 用 `maven:3.9.11-eclipse-temurin-21` 镜像内构建。

### B. 生产候选路径

- 用 `compose.production-candidate.yaml` 在本机构建
- 需要 2 个域名 + 公网 80/443
- 资源更紧
- 评估周期：半天到 1 天（含 mvn 构建 ~30 分钟）

### C. 公网正式部署路径

- 需要第二个公网 IP 或 SNI 多域名
- 需要真实 IdP（OIDC JWKS）
- 需要 SBOM、安全披露、备份策略
- **不在本文档范围内**——需独立项目

## 5. 与德勤"AI Native Workspace"方向的契合度

| 维度 | 评估 |
|---|---|
| **方向是否对** | ⚠️ **弱相关** —— 本体工作站是"语义治理 / 知识建模 / OWL SHACL 验证"工具，不直接是 Agent 平台 |
| **可借鉴的** | ✅ MCP 接入模式、PROV-O 审计链、SHACL 质量门禁、ChangeSet 原子提交 |
| **可借鉴程度** | 中等：可读源码学工程化思路，**不必整套部署** |
| **客户场景需要本体建模吗** | 看具体项目。金融监管 / 数据治理 / 知识图谱项目 ✅；通用 Agent 平台 / 客服 / 文档问答 ❌ |
| **德勤内部已有类似工具吗** | 通常有 Palantir / TopQuadrant / Stardog 等商业本体平台 |

**判断**：如果何大人的目标客户**真的**在做"语义治理 / 数据本体 / OWL SHACL"，这个值得研究。如果只是"AI 应用开发"，**跳过这套**，直接看 MCP / Agent 工程化文档。

| 选项 | 工作量 | 风险 | 价值 |
|---|---|---|---|
| **a) 跳过**（推荐） | 0 | 0 | 若不需语义治理，省 6 GB 资源 |
