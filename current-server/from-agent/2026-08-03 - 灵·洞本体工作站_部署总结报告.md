## 🏗️ 最终架构

```
浏览器
  ↓ http://101.33.212.119
  ↓
nginx:80（现有）
  ├─ /api/v1/*                → 127.0.0.1:19080 (caddy) → caddy path 路由 → api:18080
  ├─ /api/platform/*          → 127.0.0.1:19080 (caddy) → caddy path 路由 → web:13100 (vite worker)
  ├─ /api/demo-auth/*         → 127.0.0.1:19080 (caddy) → caddy path 路由 → web:13100 (vite worker)
  ├─ /studio/*                → 127.0.0.1:19080 (caddy) → web:13100 (vite base path)
  ├─ /login, /account, ...    → 127.0.0.1:19080 (caddy) → web:13100 (vite 跳转路径)
  ├─ /assets/, /brand/        → 127.0.0.1:19080 (caddy) → web:13100 (静态资源)
  ├─ /, /admin/, /python/, /onlyoffice/, /cspaicser/  → 现有服务（Dify/OnlyOffice/...）
  └─ 其他                     → 现有服务
  ↓
caddy:19080 (loopback)
  ├─ @api_v1 = path /api/v1/*                 → reverse_proxy api:18080
  ├─ @vite_proxy = path /api/platform/* /api/demo-auth/* → reverse_proxy web:13100
  └─ 兜底所有路径                             → reverse_proxy web:13100
  ↓
compose 内部网络（ontology-platform-local-fallback_default）
  ├─ postgres:17.10-alpine (5432)
  ├─ ontology-platform-api:1.0.0 (18080 + 9091)
  ├─ ontology-studio-web:1.0.0 (13100)
  └─ caddy:2.11.4-alpine (80/443 容器内)
```

### 关键设计决策

1. **端口让步**：caddy HTTP=19080 / HTTPS=19443（仅 127.0.0.1 loopback），不暴露公网
2. **域名让步**：用字面量 `api.local` / `studio.local`（不真解析）
3. **TLS 让步**：caddy `local_certs` + `auto_https off`（自签证书，浏览器接受）
4. **HTTP/3 关闭**：UDP/443 不映射（dify-nginx 占用）
5. **身份模式**：SESSION（浏览器 cookie 登录），不用 TRUSTED_GATEWAY
6. **演示账号**：直接 PG INSERT（bootstrap 一次性，永久标记）

## 🐛 8 个关键 Bug 和修复（永久规则）

### 1. gcr.io 在国内不通
- **现象**：distroless 镜像拉取 timeout 30s+
- **修复**：所有 `gcr.io/*` 换 `gcr.m.daocloud.io/*`
- **永久规则**：⚠️ 国内部署永远用 `gcr.m.daocloud.io` 替代 `gcr.io`

### 2. build-production-image.sh 必须挂载 Maven settings.xml
- **现象**：mvn 走 Maven Central 3KB/s，30+ 分钟
- **修复**：docker run 时 mount `/root/.m2/settings.xml` → 阿里云 38KB/s，2 分钟
- **永久规则**：⚠️ 任何 build container 都要 mount 宿主 maven settings

### 3. Caddy `auto_https off` 不自动 listen :80
- **现象**：caddy 只 listen :443，nginx 拿到 connection reset
- **修复**：显式定义 `:80, :443` server block
- **永久规则**：⚠️ Caddy auto_https off 必须显式 `:80, :443`

### 4. docker compose restart 不重读 .env
- **现象**：改 .env 后 restart 容器，env 不变
- **修复**：用 `docker compose up -d --force-recreate` 强制重建
- **永久规则**：⚠️ 改 .env 后必须 `up -d --force-recreate`，不能用 restart

### 5. compose 文件硬编码 env 不读 .env
- **现象**：compose.yaml 写 `ONTOLOGY_ALLOWED_ORIGINS: http://localhost:13100` 永远生效
- **修复**：用 `${VAR:-default}` 占位符
- **永久规则**：⚠️ compose 改 env 时必须用 `${VAR:-default}` 占位符

### 6. 本体 v1.0.0 密码必须 ≥15 字符
- **现象**：admin/admin（5 字符）登录 401
- **根因**：`validatePassword(value.length() < 15)` 强制
- **修复**：demo 账号密码改成 `admin1234567890`（16 字符）
- **永久规则**：⚠️ 本体 v1.0.0 任何 demo 账号必须 15+ 字符
- **运维**：5 次失败锁 15 分钟（`DELETE FROM identity_login_throttles;` 立即重置）

### 7. vite 部署子路径必须双修
- **现象**：CSS/JS 404 + React Router 跳转 404
- **修复**：
  - (A) build-time: `vite.config.ts` 加 `base: '/studio/'` + 重建 web 镜像
  - (B) runtime: nginx regex location 兜底 13 个 vite 路由
- **永久规则**：
  - ⚠️ vite base 改 `<script src>` / `<link href>` / `url()` 资源路径
  - ⚠️ vite base **不**改 React Router `<Link href="/xxx">` 跳转路径
  - ⚠️ 改 vite.config.ts 必须 `docker build --no-cache`

### 8. Caddy 路由必须用 path 不用 host
- **现象**：vite 启动时调 `/api/platform/auth/status` 401，红框 "A valid platform session is required"
- **根因**：nginx 传 `Host: api.local`，Caddy host 路由把所有 `/api/*` 转到 api 容器，绕过 vite worker
- **修复**：Caddy 改 `@api_v1 path /api/v1/*` + `@vite_proxy path /api/platform/* /api/demo-auth/*` 路径路由
- **永久规则**：
  - ⚠️ 多服务反代用 path 路由，不用 host 路由（nginx 会改 Host）
  - ⚠️ vite worker 才是 `/api/platform/*` 和 `/api/demo-auth/*` 真正 handler
  - ⚠️ vite 应用启动时调 `auth/status` 和 `demo-auth/status`——这俩必须能 200

### 顺带修复（不算独立 bug 但都堵了）

- **CSRF 拒绝公网域名**：`ONTOLOGY_ALLOWED_ORIGINS` 加 `http://101.33.212.119` + `http://api.local` + `http://studio.local`
- **Spring Security 兼容 Python bcrypt**：用 `bcrypt.gensalt(rounds=12, prefix=b'2a')` 显式生成（之前怀疑 $2b$ 不兼容，但实际是密码长度限制）
- **LoginRequest 强制 email 格式**：`admin@local` 不行（无顶级域），`admin@ontology.local` OK
- **identity_organization_memberships 用 joined_at 而不是 created_at**
- **identity_organization_roles 没有 granted_at 字段**

### 重置密码 / 账号

```bash
# 1. 生成 BCrypt hash（$2a$ 12 rounds）
HASH=$(python3 -c "import bcrypt; print(bcrypt.hashpw(b'NEW_PASSWORD', bcrypt.gensalt(rounds=12, prefix=b'2a')).decode())")

# 2. 更新 hash
docker exec ontology-platform-local-fallback-postgres-1 psql -U ontology -d ontology_platform \
  -c "UPDATE identity_users SET password_hash='$HASH', updated_at=now() WHERE email='admin@ontology.local';"

# 3. 清 throttle（避免 5 次失败锁 15 分钟）
docker exec ontology-platform-local-fallback-postgres-1 psql -U ontology -d ontology_platform \
  -c "DELETE FROM identity_login_throttles;"
```
