# 本体让步部署方案

## 一句话结论

**✅ 完全可以让本体工作站主动让步，不动现有任何服务。**

何大人这个思路是正解——所有"硬阻塞"都是本体工作站的默认行为，不是它的真实需求。**本体让步 5 项**（端口 / 域名 / TLS / 备份目录 / 镜像源）就能跑通完整生产模式。

## 2. 本体让步清单（5 项）

### 让步 ①：端口让步

| 本体原端口 | 现占用情况 | 让步方案 | 安全目标 |
|---|---|---|---|
| **80** (Caddy HTTP) | ❌ nginx 占 | 改 **19080**（仅 127.0.0.1） | ✅ 安全 |
| **443** (Caddy HTTPS) | ❌ dify-nginx 占 | 改 **19443**（仅 127.0.0.1） | ✅ 安全 |
| **443/UDP** (HTTP/3) | ❌ dify-nginx 占 | **完全关闭** | ✅ |
| **8080** (API 内部) | ⚠️ dify-nginx 占（公网） | API 容器内仍是 8080，但**不映射 host** | ✅ 安全 |
| **3100** (Web 内部) | ⚠️ yuxi-web-dev 占 | Web 容器内仍是 3100，但**不映射 host** | ✅ 安全 |
| **18080** (API loopback) | ❌ agentteams-controller 占 | 改 `ONTOLOGY_API_PORT=19081` | ✅ 安全 |

**实现**：
- Caddy 端口：`127.0.0.1:19080:80` + `127.0.0.1:19443:443`（不暴露公网）
- API / Web：用 `expose`（容器间通信）而非 `ports`（host 映射）

### 让步 ②：域名让步

**本体 Caddyfile 要求 FQDN**（生产模板强制）：
- 原配置要 `api.example.cn` / `studio.example.cn`（真实可解析域名）
- Caddy 默认 ACME 申请 Let's Encrypt，**非真实域名必失败**

**让步方案**：用本地假域名（DNS 不需要真解析）
```bash
# .env.production
ONTOLOGY_API_DOMAIN=api.local
ONTOLOGY_STUDIO_DOMAIN=studio.local
```

**`.local` 不影响容器内 Caddy 工作**——Caddyfile 用变量占位符，只在 Caddy 启动时校验 FQDN 格式（含 `.`），不真去 DNS 解析。

### 让步 ③：TLS 让步（关闭 ACME，改自签证书）

**本体 Caddy 默认 ACME**：会去 Let's Encrypt 申请证书，必然失败（`.local` 无效）。

**让步方案**：修改 Caddyfile 加 `local_certs` 指令（或环境变量 `CADDY_LOCAL_CERTS=true`）
```caddyfile
{
    local_certs    # ← 关键：用本地自签证书，不申请 ACME
    admin off
}

api.local {
    reverse_proxy api:8080
    ...
}
```

**结果**：
- ✅ 容器内 HTTPS 工作（自签证书）
- ✅ 浏览器访问会显示"不安全"，需手动加例外
- ✅ 现有 nginx 反代在前面，公网仍可走 HTTP（不暴露 TLS 警告给用户）

### 让步 ④：备份目录让步

**本体备份默认 `./backups`**（相对当前路径），备份文件可能散落各处。

**让步方案**：挂到 vault 集中备份
```bash
# .env.production
ONTOLOGY_BACKUP_DIR=/root/vault/backups/ontology
```

**额外动作**：写个 cron 把 `/root/vault/backups/ontology/` 推送到 git：
```bash
# /root/bin/ontology-backup-sync.sh
# 每天 02:00 把昨天的备份 commit + push
```

### 让步 ⑤：镜像源让步（国内加速）

**本体用 gcr.io/distroless 镜像**（Google，国内拉取慢）+ Maven Central 依赖。

**让步方案**：
```bash
# 1. Maven 镜像：/root/.m2/settings.xml
cat > /root/.m2/settings.xml <<'EOF'
<settings>
  <mirrors>
    <mirror>
      <id>aliyun</id>
      <name>aliyun</name>
      <url>https://maven.aliyun.com/repository/public</url>
      <mirrorOf>central</mirrorOf>
    </mirror>
  </mirrors>
</settings>
EOF

# 2. Docker mirror：已有配置（2026-06-16 加的 docker 加速器）
# /etc/docker/daemon.json 已含 3 个国内 mirror
```

**效果**：
- Maven 首次依赖下载从 30-60 分钟 → **5-15 分钟**
- Docker 镜像构建从可能超时 → **正常完成**

## 3. 不需要让步的（本体本来就好）

| 项 | 状态 | 说明 |
|---|---|---|
| **PostgreSQL** | ✅ | 本体自带 `postgres:17-alpine` 容器，不复用我们现有 PG16，**完全隔离** |
| **TDB2** | ✅ | 单实例内嵌存储，无外部依赖 |
| **Java 21** | ✅ | distroless 镜像内自带，**宿主 Java 坏也没事** |
| **Node 24** | ✅ | distroless/nodejs24 镜像内自带，**宿主 Node 版本无影响** |
| **Caddy** | ✅ | 反代 + 安全头，**不需要让**（只需让步端口和 TLS） |
| **资源（6.25 GB RAM / 5.5 CPU）** | ⚠️ 紧但够 | 30 GB 中现有 21 GB 用，余量 9 GB |

## 4. 修改后的 compose.production.yaml（关键 diff）

```yaml
# services/platform-api/compose.local-fallback.yaml
name: ontology-platform-local-fallback

services:
  postgres:
    image: postgres:17-alpine   # 本体自带，不动
    ...
    
  api:
    image: ontology-platform-api:1.0.0
    environment:
      - PORT=18080              # 容器内端口（仅 Caddy 可见）
      - ONTOLOGY_API_DOMAIN=api.local
      ...
    expose:
      - "18080"                 # 仅容器间可见，不映射 host
      - "9091"                  # Prometheus 指标
    # 不映射 host port（删掉原 "127.0.0.1:18080:8080"）
    
  web:
    image: ontology-studio-web:1.0.0
    environment:
      - PORT=13100              # 容器内端口（仅 Caddy 可见）
      - PLATFORM_API_BASE_URL=http://api:18080/api/v1
      ...
    expose:
      - "13100"                 # 仅容器间可见
    # 覆盖原 CMD 的硬编码 --port 3100
    command: ["./node_modules/vinext/dist/cli.js", "start", "--port", "13100"]
    
  caddy:
    image: caddy:2.11.4-alpine
    environment:
      ONTOLOGY_API_DOMAIN: api.local
      ONTOLOGY_STUDIO_DOMAIN: studio.local
      CADDY_LOCAL_CERTS: "true"   # ← 用自签证书，不申请 ACME
    ports:
      - "127.0.0.1:19080:80"      # ← 仅 loopback，不暴露公网
      - "127.0.0.1:19443:443"
      # - "443:443/udp"          # ← 关闭 HTTP/3（UDP 443 被 dify 占）
    volumes:
      - ./Caddyfile.local:/etc/caddy/Caddyfile:ro   # ← 用本地化 Caddyfile
      - caddy-data:/data
      - caddy-config:/config
    
  backup:
    profiles: ["operations"]
    ...
    volumes:
      - rdf-data:/source/rdf:ro
      - release-data:/source/releases:ro
      - /root/vault/backups/ontology:/backup         # ← 备份到 vault
    networks: [backend]
    
  restore:
    profiles: ["operations"]
    ...
    volumes:
      - rdf-data:/target/rdf
      - release-data:/target/releases
      - /root/vault/backups/ontology:/backup:ro
    networks: [backend]

networks:
  backend:
    internal: true
  edge:

volumes:
  postgres-data:
  rdf-data:
  release-data:
  caddy-data:
  caddy-config:
```

**对应的 Caddyfile.local**（加 `local_certs` + 改 `{$...}` 为字面量）：
```caddyfile
{
    local_certs
    admin off
    auto_https off
}

api.local {
    encode zstd gzip
    reverse_proxy api:18080
    header { /* 安全头保持原样 */ }
}

studio.local {
    encode zstd gzip
    reverse_proxy web:13100
    header { /* 安全头保持原样 */ }
}
```

**新增 nginx 反代**（不动现有任何配置）：
```nginx
# /etc/nginx/sites-available/ontology.conf
server {
    listen 80;
    server_name _;
    client_max_body_size 200M;
    
    # 本体 Web 工作室
    location /studio/ {
        proxy_pass http://127.0.0.1:19080/;
        proxy_set_header Host studio.local;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
    
    # 本体 API（带 gateway token 注入）
    location /api/ {
        proxy_pass http://127.0.0.1:19080/api/;
        proxy_set_header Host api.local;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        # gateway token 由 nginx 注入，不进浏览器
        # token 写在 /etc/nginx/conf.d/ontology-secrets.conf (chmod 600)
        include /etc/nginx/conf.d/ontology-secrets.conf;
    }
}
```

## 8. 风险再确认

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|
| **首次 Maven 构建慢** | 中 | 30-60 分钟 | 阿里云镜像 |
| **distroless 镜像拉取** | 低 | 5-15 分钟 | 已有 Docker mirror |
| **自签证书浏览器警告** | 高 | 用户体验 | nginx 反代在前面，公网 HTTP-only |
| **API OOM（3GB 限值）** | 低 | 服务挂 | Spring Boot 默认 512MB-1GB，3GB 充足；监控 + 重启 |
| **TDB2 单实例** | 必然 | 不能 scale > 1 | 官方明确禁止，**这是设计** |
| **GPL-2.0 传染** | 必然 | 商业闭源风险 | **只 demo，不进客户交付** |
| **UAT 未过** | 高 | 实际使用可能踩坑 | 仅学习/评估用 |
