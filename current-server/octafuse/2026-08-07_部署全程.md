## 关键发现
1. **GHCR 拉不动**（4 小时没拉完 1 个镜像）：走 GitHub Pages CDN，单层 49MB 速度 33B/s
2. **本地 build 走阿里云 APK 镜像**：~100s/镜像，比 GHCR 拉快 1000x
3. **`docker build` → `docker buildx build --load`**：Docker 29.x 默认走 buildx，不自动 load 到 daemon
4. **`nohup setsid` 防父进程 SIGKILL**：跟父 exec 完全脱离
5. **admin login 路径**：用 `/api/auth/login`，不是 `/api/admin/auth/login`
6. **MASTER_KEY 默认值 `sk-dev-admin-key`**：迁移 0002 写入，必须替换
